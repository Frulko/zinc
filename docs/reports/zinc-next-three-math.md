# Guarded native three.js math

ZN-597 accelerates the unchanged QuickJS versions of Matrix4 multiply/compose/invert, Matrix3 normal matrices, Vector3/4 matrix application, Sphere transforms, Frustum sphere/object culling, Quaternion Euler conversion and Object3D local matrices. The table and pinned source signatures belong to the Three extension. The existing QuickJS hook registry obtains its compiled default entry from the extension, so CLI and statically linked script contexts use the same initialization. User source transforms run first; pinned-library recognition runs last. The loader only supplies a generic source hook, before its source-cache fingerprint. Registration is appended after class declarations and is safe when the native binding is absent. `ZINC_JS_ACCEL=0` disables source changes and native installation, including already transformed bundles. Set the flag before launch. The same hook covers the main loader and both `zinc:script` module-loading routes; sandboxed contexts without a binding keep the JS methods.

Only the exact SHA256-pinned r186 core and original r162 module match. Unknown or edited libraries stay unchanged. r186 is vendored; r162 proof uses the existing checksum-pinned external test input. The production r162 selection/vendor work belongs to ZN-540 and is not claimed here. No duplicate library or vendor-source rewrite is added.

Each wrapper retains its original JS function through QuickJS's traced CFunctionData values. Public class/prototype and own-data descriptor checks reject Proxy/exotic/accessor inputs, sparse/non-numeric arrays, unwritable outputs and nested method overrides before mutation. Dense input doubles are copied for aliases; ordinary setters preserve descriptors. A failed guard calls the original exactly once with the original receiver and arguments. No fallback occurs after native mutation. Quaternion callbacks run after writes, with no borrowed pointer live across the JS call. Frustum object culling updates the actual upstream scratch sphere, and rejects an escaped scratch center aliased to a plane normal.

Arithmetic preserves each release's expression order and disables fused multiply-add. The releases have different Matrix4 inversion formulas; each uses its own. Trigonometry uses Zinc's existing deterministic `zn_js_sin/cos` functions.

The host test compares separate original-JS and native-installed module instances. Both versions passed 100000 deterministic inputs per actual method plus 112 edge cases; signed zero and NaN use `Object.is`. The release `-O3` build disables fused multiply-add. Private compile-only hit counters prove the normal paths execute every kernel and malformed scenarios execute retained-original fallbacks. The default T0 uses 1000 cases plus the same 44 targeted scenarios. Adversarial checks include getters/Proxy traces, aliases, frozen/sparse arrays, custom returns, partial mutations on errors, callbacks, coercion, embedded-NUL Euler orders and the escaped scratch sphere. The actual loader passes on→off→on cache checks and same-path/same-length edited-source rejection. The unchanged `examples/js-three` lighthouse renders three identical 800×500 frames with acceleration on/off (hashes `adce9b77428fb3ea`, `46c410b544059e4b`, `01b6661e52705ac4`); PNG bytes match too. Direct and imported embedded core script modules select native methods when enabled under the interpreter and native AOT. The separately vendored legacy script plugin used inside an outer JavaScript program keeps its JS methods; numeric results match, and no QuickJS API is mixed across those versions. The original one-argument context-hook ABI is retained and an old-interface consumer links and runs.

An isolated production-build QuickJS host reports +3499 B of accounted heap for an unused binding; a loaded native r186 module adds 3894 B over its plain library, r162 3790 B. These are accounted heap bytes, not RSS. The report's historical 1.61→0.084 μs multiply and 7.9→6.0 ms frame results belong to the prototype. The unchanged Hero builds to 7978168 B with 9539880 B of generated C++/shared/PCH source, within the original 8000000/10000000 B limits. No new timing or ≤4.5 ms claim is made; that quiet 500-mesh gate remains open.

Proposed decision (engineering scores in RULES order): static extension/public guards 5/3/4/5/5/5/5=62; optional DSO/new QuickJS table 5/3/5/3/5/4/2=56; additional raw-private accessor 5/4/4/2/4/3/2=52. Keep the existing static QuickJS extension archive and public APIs. Revisit raw access only after an owner-selected measurement identifies guarded setters as the bottleneck.
