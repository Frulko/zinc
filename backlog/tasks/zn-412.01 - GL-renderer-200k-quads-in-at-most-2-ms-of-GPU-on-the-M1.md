## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
plugins/display-gl/src/gl_renderer.cpp replays bouncing-ball's 200k balls in 15.4 ms per frame with glFinish (ZINC_GL_TIME), 5.5 ms of it the CPU building 4 vertices of 56 bytes per quad (45 MB a frame, 25 draws of 8192 quads). Compact per-quad data (instanced quads where the API has them, short attributes), solid square rects through a cheap shader path, and occlusion of opaque square rects with the depth buffer (opaque ones front to back with depth writes, the rest in paint order with the depth test), keeping the software raster's pixels within the tolerance policy.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
usage: n/a

Done (D49), plugins/display-gl/src/gl_renderer.cpp:
- Occlusion pass: opaque square RECTs and CLEARs outside clips first, front to back with depth writes, through a solid program (24-byte instances on desktop GL, 16-byte vertices on GLES 2). Every other command is then depth-tested at its paint depth; CLEAR inside a clip becomes a quad.
- Depth buffers: FBO 24 bits (16 bits on GLES 2 without OES_depth24), window depth 24 (sdl.cpp), EGL config with depth and a fallback without (kms.cpp).
- Culling of lists of 2048 commands or more through the new zrt::raster::cull / cull_rows (runtime/raster.cpp: 8 px tiles, bitmask rows, superblocks). Only the visible commands are walked afterwards.
- Knobs: ZINC_GL_OCCLUDE, ZINC_GL_CULL, ZINC_VSYNC (sdl.cpp). ZINC_GL_TIME now prints a GL_TIME_ELAPSED GPU time; ZINC_GL_STATS prints the culling time and the hidden count.
- Fixed on the way: the plugin cache key missed the files beside the sources (gl_renderer.cpp is #included) and runtime/zrt_raster.h (src/tc/plugin_build.cpp; tests/t1/plugin_key.sh checks it).

Measured on bouncing-ball 200k in a window (M1 Pro, 640x480 surface):
- Before: replay 15.4 ms (GPU done), CPU 5.5 ms, 200k quads.
- Now: GPU 1.36-1.38 ms by timer query (AC2), 46k quads, CPU submission 3.6 ms (2.9 ms of it culling): the CPU part of the old AC1 moved to ZN-412.05.
- Without vsync: GL replay about 114 fps, CPU raster 95 fps (the 125 fps pacing and the script cap both).
- Rejected: culling on 4 threads by bands (3.4 ms).

A bug found in my own change: the occlusion pass left glDepthMask off, so the next frame's depth clear did nothing (93% of pixels wrong on tests/data/tiles); fixed before measuring again.
