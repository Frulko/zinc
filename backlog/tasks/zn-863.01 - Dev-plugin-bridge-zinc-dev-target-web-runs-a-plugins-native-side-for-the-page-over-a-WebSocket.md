## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
W0602 says 'the native side X has no browser backend: its calls throw ZnUnsupported' (Device, Lvgl, Cdp, Process, Ipod...). Following docs/reports/web-bridge-research.md §3 (JSON-RPC envelope, OBS-style handshake, token, binary frames): the dev server (src/cli_web.cpp), on loopback and same origin as the page, loads the plugin's native library and answer the page's calls; the generated web entry calls the bridge when no browser backend exists and the bridge answered hello, else ZnUnsupported as today. plugin.json web level: native | bridge | none, W0602 says which. Local development only (owner, 2026-10-30): a hosted page never gets process, fs or devices from a server; the online demos use browser backends, the in-page device simulator and a demo mode instead.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-10-30. zinc dev --target web finds the native sides with no browser backend (requireNative in the staged modules, minus the plugins' web impl), writes build/.zinc-web-dev/bridge-host.mjs (imports of their spec modules + targets/web/bridge-host.mjs) and runs it with zinc run (QuickJS, the real native libraries), loopback, random port, 32-hex token in the page config; stopped with zinc dev. Page side: requireNative falls back to Z.bridge.call (sync XHR: native calls are synchronous); callbacks and settled promises come with each reply and from a sync drain after a long poll (/wait), and run as tasks in the host's order, never inside a call (run() registers onExit after closeStdin). zinc:process now rotates its handles: with lowest-free reuse an exit event still on its way reached the next child. No bridge with --lan, never in an export. Proof: tests/t1/web_bridge.sh (callback, promise, 403 without token, bridge gone after zinc dev); examples/esp32-widgets under zinc dev: web-real-test --dev --render dom, no problem, reacts (Lvgl and Device through the bridge). Not done (description, not a criterion): plugin.json web level native|bridge|none.
