## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
zinc add <git-url[@ref]|gh:|file:// or https:// .tar.gz/.tgz/.tar> [dir] copies the plugin into plugins/<name> (no .git, links and special files refused, no hooks) and writes zinc.json lock.plugins.<name> {source, commit|sha256} (zinc.json rewritten by yyjson, two-space pretty). zinc install fetches each locked plugin again at the commit / checked against the sha256. fetchTemplate now takes url@ref for every git URL (templates too). tests/t1/plugin_add.sh: git + archive plugins pinned, the project runs with them, a second checkout gets identical bytes although the repo moved on, a changed archive is refused, a plain directory is refused; templates_remote and tests/run --changed (48) pass. docs/plugins.md section. usage: n/a
<!-- SECTION:NOTES:END -->
