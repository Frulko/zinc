## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
2026-10-22 (parallel worktree).
- app/tour.ts: the steps (language, welcome, example, editor, run, console, error, completion, palette, devices, templates), the step signal, start/next/back/end, the marker. components/Tour.tsx: four shades around the part a step is about (they take the pointer, the part keeps working), an accent ring on it, and a card placed under it, else above, else inside its lower corner (its height measured the frame before), with progress, Skip the tour, Back, Next/Finish; the first card lists the languages (their own names, the current one checked; a press switches Atelier at once and saves lang in config.json, D159). Parts are node refs on the start view's first examples, the Hello card and the templates row, the editor card, the run control, the console card, the palette button and the engine pill.
- Waiting steps go on by themselves: example (a sketch opened), run (a run started), error (the tour turns Hello's clear( into clearr(, saves and checks; fixed by hand or with Fix it for me; leaving the step takes the mistake back, so the tour never leaves a sketch broken). Next always works; the steps after example open Hello when no sketch is open. The templates step points to Help > Learn and has an Open the lessons button (owner's addition).
- When: a first launch (no last sketch and no marker), after the start view; under a test's ZINC_ATELIER_HOME only with ZINC_ATELIER_TOUR=1, so the other tests are unchanged. Help > Tour of Atelier (help-tour) replays it from the welcome. Escape and Skip end it. Marker: ~/.zinc/atelier.json (<ZINC_ATELIER_HOME>/.atelier.json under a test): {tour: done, tourVersion: 1, skipped}, other keys kept. Decision: the language is not stored in atelier.json as the audit proposed but in config.json lang (D159), the one place the CLI reads too.
- Script verbs: tour:next, tour:back, tour:skip, tour:fix, tour:step ([tour] <id> <x y w h>), tour:lang:<code>.
- Texts atelier.tour.* in en fr es it de (31 keys).
- Test: tests/t1/atelier_tour.sh (PASS): LANG=fr_FR gives the French language card, Spanish chosen there is saved and the next cards are Spanish; the steps in order with a box inside the window for each part; Hello opened, a run and the fix advance by themselves; the sketch is as it was; the done marker; a second launch has no tour, Help > Tour replays it, Escape skips it and the marker says skipped. Looked at: the language card (fr), welcome, error and templates cards (es).
- The three Atelier T1 tests that set ZINC_HOME (atelier_languages, atelier_help, atelier_tour) link toolchains, cache, index and sysroots of the real home into their scratch home: with a bare scratch ZINC_HOME, Atelier's native plugins made zinc download zig again on every run.
- For backlog/later.md: (1) the tour on a real window: the card's placement and the run step with a real sketch window (only headless here); (2) the error step's status line first says main.ts saved (the save's notice) before the problem: a quiet save for the tour would show the problem at once; (3) a Take the tour link on the start view, if Help > Tour proves hard to find.
