## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done: chooseAppVersion at the launch of a .zapp or a fused app with zinc.json app.id and update.publicKey: ~/.zinc/apps/<id>/ trial left over -> roll back (drop staged, message); current newer than the archive -> run it; staged newer -> run on trial (write trial; promote to current when it exits normally (atexit) or after 5 s (thread); a failed run exits without promoting so the next launch rolls back). Each candidate is unpacked and checked by unpackZapp, and must carry the same app id. zinc update-app stages the verified download.
