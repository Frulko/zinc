## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A design report (docs/reports/ui-primitives-like-react-native.md) lists what zinc:ui imposes today (default looks such as the dark Button, card shadows, kit-only components, className-only features) against React Native's primitives (unstyled View, Text, Pressable, style objects and StyleSheet, every visual property in style, a design system only if you add one), and decides what changes, with a decision record
- [ ] #2 The primitives draw nothing a program did not ask for, and every visual property (colours, borders per side, radius per corner, shadow, opacity, transform) can be given as a style object as well as a class; the kits and the examples keep their look by asking for it, with the pixel goldens unchanged or re-baselined on purpose
- [ ] #3 A program that imports zinc:ui and only its primitives compiles and starts lighter than today (measured and logged)
<!-- AC:END -->

Step 3 (style keys, text and layering): style objects take zIndex (n.z, as z-10), fontStyle (italic), textTransform, textDecorationLine (the deco bits), textDecorationColor and textDecorationStyle (solid, double, dotted, dashed: no class; a colour field decoC and the style in deco's bits 3-4, drawn by decoLine in ui.ts and as text-decoration-color/style by targets/web/dom.js), textShadowColor/Offset (tsColor, tsAlpha, tsX/Y, as text-shadow-md text-shadow-red-500; textShadowRadius accepted and drawn sharp, as the classes), fontWeight 100 to 900 (weight, as font-thin..font-black; the 0/1 of a hand-made ui.Style still read as normal/bold; getNumber reads 100..900), pointerEvents auto/none (noPointer), cursor (the CURSOR_OF codes), shadowLevel (shadow-sm..xl), and an alpha or transparent on color (colorAlpha, as text-white/50), borderColor (borderAlpha; transparent is border-transparent's -1) and shadowColor (a new shAlpha that multiplies shadowOpacity, as React Native). Each key is a PROP id (115 to 127) written by writeProp, so a style-only program needs no class parser for them (step 6). A literal colour without alpha now resets its alpha (a class alpha or an earlier layer); a conditional between colours always carries the alpha key. src/res/res.cpp bakes the italic faces when the lowered source names fontStyle (the lowered style object no longer holds the word italic). dom.js: color(-1) is transparent (border-transparent drew a white inset band on the web; the native renderers draw nothing).
