## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A design report (docs/reports/ui-primitives-like-react-native.md) lists what zinc:ui imposes today (default looks such as the dark Button, card shadows, kit-only components, className-only features) against React Native's primitives (unstyled View, Text, Pressable, style objects and StyleSheet, every visual property in style, a design system only if you add one), and decides what changes, with a decision record
- [ ] #2 The primitives draw nothing a program did not ask for, and every visual property (colours, borders per side, radius per corner, shadow, opacity, transform) can be given as a style object as well as a class; the kits and the examples keep their look by asking for it, with the pixel goldens unchanged or re-baselined on purpose
- [ ] #3 A program that imports zinc:ui and only its primitives compiles and starts lighter than today (measured and logged)
