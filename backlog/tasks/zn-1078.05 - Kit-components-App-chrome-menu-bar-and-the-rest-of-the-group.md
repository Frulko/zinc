## Implementation notes

- Research: [CUI App chrome](https://github.com/yappologistic/CUI/blob/master/docs/components-more.md#app-chrome), [CUI design](https://github.com/yappologistic/CUI/blob/master/docs/design.md), [WAI toolbar](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/), [WAI menus](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/). Reused Button/IconButton/Popover/Progress/ResizeHandle and ui/dnd; no new dependency or import-time registration.
- Added one App chrome family: responsive overflow Toolbar (including trailing-slot width), StatusBar/StatusItem, controlled DocumentTabs and recursive DockLayout. Bars inherit surfaces with an inner hairline. MenuBar supports F10, optional mnemonics, title traversal and hover switching through a Closed/Open controller; stale accelerator callbacks validate the bar's generation. Existing pointer API stays compatible and ResizeHandle adds keyboard resize.
- Tabs support stable identity, dirty/closable state, caller-confirmed close, reorder, cycle keys and pointer drag. Docking supports centre/edge drops, keyboard Panel actions named after visible panels, divider resizing, close/reopen in original groups, saved layouts and empty-branch compaction. Split ratios divide the available flex space after the handle. Closed panels stop building; unavailable plugin IDs remain in the data.
- Saved data validates a copy before application: source length65536, depth16, nodes95, panels48, unique IDs, selections and ratios. Moves reject unknown panels/targets. Gallery saves only on request and shows storage/parse errors without replacing the current layout. No existing app data is migrated.
- Filled the shared ui/dnd cancellation gap with public cancelDrag(): target leave clears highlights and later release cannot drop. Its lifecycle is Idle/Dragging/Finishing through one transition function; finally restores idle after callbacks throw, disposal cancels and source/target records validate generations. Documented API; the direct std-module export has no generated d.ts. Shortcut hints retain minus keys using bindKeys' trailing-hyphen convention (also needed by ZN-1078.06).
- Engine gaps were fixed by the coordinator's separate tasks, without UI workarounds: ZN-1079 keeps local JSX node provenance; ZN-1081 removes stale focus callbacks before handles are reused. The original same-frame drag → Escape → release → second drag fixture passes after1081; no event timing was changed. Temporary1081 mirror was restored before rebase and never committed here; this branch rebased onto the actual engine commits.
- AC1 proof: zinc check of the gallery passes; kit_chrome passes interpreter/QuickJS (malformed saves, split/move/save/close/reopen, visible panel lifecycle, same-frame drag cancellation/restart, tab/menu keyboard behavior, narrow toolbar overflow and minus shortcuts). ui_dnd passes its existing native/AOT behavior plus interpreter cancellation and throwing-drop cleanup. kit_actions rerun passes after the shared variant-aware icon-color fix.
