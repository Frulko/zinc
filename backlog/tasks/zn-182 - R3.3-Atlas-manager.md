Done 2026-11-09 (worker agent). runtime/gl_replay.cpp: the single 1024 atlas that was reset whole when full becomes up to 4 pages (APAGES) made as needed, each a shelf allocator with a 1 px gap; a page records the frame it was last used in. When no page has room (or the 16384-slot glyph table is 3/4 full) the page used longest ago that holds glyphs is evicted: flush() first (queued quads may sample it), its used rows cleared to zero (bilinear sampling of scaled glyphs finds no stale ink), its glyphs dropped from the table (rehash). Glyphs of this frame on an evicted page come back lazily. GLES 2 keeps a shadow per page with its own dirty rows (ZN-725 upload-before-draw kept). TEXT under a matrix switches the filter of every page. ZINC_GL_ATLAS=<px> (64..1024) shrinks the pages for tests. Stats: ZINC_GL_STATS line 'glyph atlas: N of 4 pages of S px, G glyphs, X% of their rows in use, E pages evicted'; ZINC_PROFILE=json gl_atlas_pages/glyphs/occupancy/evictions. Docs: docs/plugins/display-gl.md tuning table.
Proof: tests/t1/gl_atlas_churn.sh (written, run once): tests/data/gl_atlas_churn draws 200 characters x 4 sizes a frame, sizes moving each frame, on 128 px pages: 12 frames, 579 page evictions, 4 pages, exit 0, last frame identical (max 0) to the run with default pages. The GLES 2 path (GLR_CORE 0) only syntax-checked on the Mac with the GLES2 headers (no warning in the new code); not run on a Pi.
Research (sonnet, 2026-11-09): Skia GrDrawOpAtlas (https://skia.googlesource.com/skia/+/main/src/gpu/ganesh/GrDrawOpAtlas.cpp): 4 pages of plots, LRU per plot by flush token, reclaims only after reaching the max page count; flush before evicting a region queued vertices reference; 1 px padding; invalidate the glyph-key map on eviction. Chose whole-page eviction (simplest, no plot bookkeeping) with the same LRU and flush rules.
Not done (later.md): - ZN-182: plots inside a page (Skia) instead of whole-page eviction, and RGBA pages for colour glyphs (emoji), when an app mixes many sizes or needs colour fonts.
Proposed tests: tests/t1/gl_atlas_churn.sh (windowed GL, ~5 s, <300 MB); a Pi 3B+ run of gl_atlas_churn with ZINC_DISPLAY=gl to prove the GLES 2 shadow path.
