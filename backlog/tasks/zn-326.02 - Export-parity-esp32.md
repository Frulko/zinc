## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
zinc export --target esp32 writes core.bin (the core firmware, 0x0), app.bin ("ZNAPP1", length, then an upload stream: the load line and the ZBC, at 0x300000) and flash.sh (pinned esptool, else PATH). The firmware reads that flash region at start-up and feeds it to the core (no new protocol code), then waits for uploads. The firmware no longer built with today's runtime: rt.h threw without exceptions, machine.cpp used mmap, alloc.cpp was not linked; guarded for ESP_PLATFORM and rebuilt (prebuilt image 841600 bytes, no warnings). tests/t1/export_esp32.sh: the exported hello boots in the pinned QEMU with no host and prints the native bytes in about 1 s; a program over 48 KB is refused. tests/t2/esp32_qemu.sh, export_wasm, device_modules and tests/run --changed (48) pass. usage: n/a
