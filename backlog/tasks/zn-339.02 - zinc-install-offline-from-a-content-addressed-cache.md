## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
fetchPlugin keeps sources by content in ~/.zinc/cache/sources: archives by SHA-256 (with their verified .sig), git trees by commit (without .git); a locked archive comes from the cache, else the mirrors as sha256/<hash>, else its URL (tc::downloadTo, each checked against the lock). zinc install --offline (ZINC_OFFLINE=1) uses only the cache and names each missing plugin ('<name>: offline: not in the local cache'). tests/t1/install_offline.sh: a warm cache installs with the sources deleted, byte for byte; a cold one fails naming greet and shout. plugin_add and plugin_sign now run under their own ZINC_HOME (they had written into ~/.zinc; the leftovers were removed) and check their refusals on an empty cache, since a warm cache rightly serves the locked bytes. tests/run --changed 50 pass. usage: n/a
<!-- SECTION:NOTES:END -->
