## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Authoring in the manner of Klynt, so that a museum makes its own installation without editing a file: a storyboard where sequences are created, named and linked by drawing connections; a sequence editor to import media from a folder, place and size them, set their timing, write captions and descriptions per language, and add hotspots; points of interest placed on a 3D model by touching it; preview from any sequence; save, load and duplicate projects; undo and redo. (Owner request, 2026-10-10: a demo app useful for mediation in museums: an interactive presentation on a touch table, photo gestures, 3D models, descriptions, presentations, in the manner of Klynt.)
<!-- SECTION:DESCRIPTION:END -->

What exists (examples/museum-table/editor, a project of its own: `zinc run examples/museum-table/editor -- <project.json>`)
- doc.ts: the document (project + undo/redo + every operation), pure; selftest.ts runs it without a window. state.ts: selection, views, commands. storyboard.tsx, sequence.tsx, inspector.tsx, main.tsx: the views. strings.ts: every text of the interface, English and French. widgets.tsx: controls and the one function that draws a medium.
- Storyboard: sequences as nodes (title, miniature of the table with the real photographs of the project folder, kinds of media, link count), links as arrows whose head follows the tangent and ends on the node's edge, dashed when the target opens over its sequence; pan, zoom (4 steps, laid out, not transformed); create (double click or N), name in every language, move, duplicate, delete; draw a link by dragging the handle under a node; label, kind, transition, target of a link; start flag; unreachable sequences dashed orange and listed in Problems; New, Open, Save, Save as (system dialogs), unsaved state, questions before losing work (open, new, close of the window); undo and redo of every operation.
- Table of a sequence (double click a node): media library (a file of the project folder with its title, source and licence; a text written in place; remove with a question when used), drag a medium onto the table, move, size by the corner, order, take off; buttons and hotspots, target chosen in a list or on a small map of the storyboard; a button stays within table.reach of an edge (the forbidden middle shows while dragging); timeline (drag a bar or its ends); captions, descriptions, audio descriptions in every language side by side; credit.
- Advanced mode (Cmd+E): exact numbers (storyboard position, item x, y, width, height, turn, button x, y), the selection as the file has it (read only), the key of every command. Same commands as the gestures.
- Interface in English and French (system language from LC_ALL / LANG, switch in the status bar), apart from the content language switch of the top bar.

Decisions (for the coordinator to file)
1. The editor is its own project (editor/zinc.json): a zinc.json has one `entry`. It imports ../src/project.ts and touches nothing else of the example.
2. Every operation leaves a project parseProject accepts (the strict loader is the only reader, so Save must never write a file that cannot be reopened): unique ids, required texts cannot be emptied, deleting a sequence or a medium takes or retargets what named it, a button is kept within reach. Only the empty project (no sequence) is not saved.
3. Undo keeps a copy of the project per step (copyProject), typing in one field merges into one step; "unsaved" compares the bytes with the saved ones, so undoing back to the saved state is clean again. Cost: one copy per step (45 KB of text for the sample).
4. An id the editor derived from a title follows the title while it still matches (sequence-1 becomes accueil): files, messages and statistics stay readable; hand-chosen ids never change.
5. A sequence's storyboard x, y is the centre of its node, 240 x 150 units (relayed to the player and the format reference).
6. Zoom by layout in four steps (50, 75, 100, 150 %) with a text size per step: sharp text, no transform (ZN-263 not needed).
7. A link shows a dot on its arrow; the label opens when the link is selected, under the pointer, or leaves the selected sequence: a storyboard with 14 links stays readable.
8. strings.ts: one line per text, a typed constant as key, English and French side by side; the window is rebuilt when the interface language changes. Tests pin MUSEUM_EDITOR_LANG=en.
9. Thumbnails: imageFromBytes of the files of the project folder, one decode per frame, reduced to 320 px, 40 kept (64 runtime images, ZN-670), least recently drawn out first.

Limits, each marked `ponytail:` in the code
- doc.ts jsonOf cuts a sequence out of the canonical text by indentation: project.ts writes whole projects only (ask the format's owner to export sequenceJson / mediaJson).
- widgets.tsx DRAWN: Latin-1, Latin Extended-A and typographic punctuation put into the font by a constant until ZN-669.
- main.tsx: a relative path argument is resolved with the shell's PWD because `zinc run <dir>` starts in the project directory; strings.ts: the system language is read from LC_ALL / LANG. Both want a function in zinc:sys.
- storyboard.tsx: no routing of arrows around nodes; sourceOf scans every sequence.
- sequence.tsx: an item is drawn upright, its rotation is a number of the advanced mode (zinc:ui does not paint rotation, ZN-263); a hotspot is shown on the first item of its medium.
- state.ts newFiles: three directory levels; a narration per language (`{lang}` in the path) is not offered.
- A panorama larger than 2^24 pixels has no thumbnail (imageFromBytes refuses it).

Found

- The pinned Lucide set has no trash-2 (it is trash); examples/nuxt-ui lists trash-2 (reported).
