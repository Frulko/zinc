## Implementation Notes

- Added caller-owned `zinc:game` (lib/std/game.ts): Scene hooks and SceneController with one guarded phase enum, Sprite delegating every drawing parameter to Frame.draw, and Playback over existing Animation/frameAt. Public updates use seconds; sprite frame durations and the reported playback clock use milliseconds. No imports register callbacks, load atlases, allocate game objects, or add another renderer/atlas format.
- The existing platformer now drives SceneController from its onFrame, renders the hero through Sprite, and advances flag Playback from the existing simulation clock (resetting on a new game). Its existing controls, game rules, batching and target manifests remain the providers. Existing n3ds-platformer, game-2d template and sprite_atlas signatures are unchanged.
- Scene transitions reject reentrancy/second start; finally restores Active after failed update/draw and Idle after failed enter/leave. Hooks still own cleanup of any partially acquired resources. Playback pause/resume/restart/completion use one enum; finite nonnegative seconds are validated and time overflow rejected before mutation.
- New Playback exposed the shared empty-animation seq[0] failure. Animation.set now rejects empty lists and nonfinite/nonpositive durations before changing the animation; the small regression is in the same T0. No caller workaround. Atlas frame/animation references and reload-sensitive duration reads remain shared; no speculative duration cache.

### Research and choice

Coordinator-delegated research, verified against primary documentation: https://docs.phaser.io/phaser/concepts/scenes (separate scene lifecycle hooks and rendering), https://phaser.io/oss/docs/api-documentation/class/animations-animationstate (per-object animation playback), https://phaser.io/oss/docs/api-documentation/namespace/animations-events (completion distinct from looping). Reuse Zinc Animation and Frame as immutable-in-identity providers with caller-owned playback state. A scene registry, ECS, object pools, events, automatic onFrame hookup and another library would add unrequested ownership and duplicate current providers; omitted. The std module table also feeds module discovery, so no duplicate LSP list was added.
