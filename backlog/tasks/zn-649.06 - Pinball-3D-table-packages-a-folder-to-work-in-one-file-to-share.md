## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
From ZN-649.04 slice 5 (2026-10-10): criterion 1 proven by tests/t1/pinball3d_editor_table.sh: Tidal Lock with its sounds (base64), images and models (text for .obj), exported by the editor (the game's packTable), plays the first 20 s (1200 frames) of the scripted game from the package with the lines of tests/data/pinball3d/play.log; the table made in the editor plays the same 15 s from its folder and from its package. Criterion 3: docs/pinball-table-format.md now has 'The package' (format, version, files as name + text or base64, table.json first). Criterion 2 is half met: making a package of a table whose folder lacks a file it names is refused and names the file (tools/table.ts pack and the editor's Export: tested); NOT done: a package that was altered or emptied after it was made is not refused when the game opens it (a missing sound stays silent with a warning). That needs a hash per file in the package and a check in PackageSource; zinc has no hash function in its standard modules today (no zinc:crypto in lib/modules.d.ts): vendor one (Monocypher's BLAKE2b is already in the tree) or expose it, then record it per file.

2026-10-11: criterion 2 done by making the package a pack of the engine (ZPK, docs/zpk.md) instead of the JSON file with base64 (the owner asked for the engine's archive, not a new one). A .zpinball holds table.json, the table's files under their names and package.json ({ format, version 2, files }). New in the engine: assets.writePack(path, names, data) (rows host.assetsPackAdd / host.assetsPackWrite, zstd level 9), and assets.mount takes a file of any extension. PackageSource mounts the file, reads every entry (the pack checks each against its SHA-256), unmounts: an altered package is refused with 'the file "x" was altered after the package was made', loadTable refuses a package lacking a file its table names ('the file "sounds/x.wav" is missing from the package'). A package inside the game's assets goes through a temporary file (packageOfBytes). JSON packages of version 1 are no longer read (none was shipped): export again from the folder. Tidal Lock: 975 584 bytes packed (1.2 MB folder). Proof: tests/t1/pinball3d_format.sh (altered, missing, not a pack; interpreter, compiled, QuickJS; the compiled tool writes the same bytes), pinball3d_editor_table (same score log from the package), pinball3d_chooser (package among the game's assets). Not measured: what the pack writer (zstd compressor) adds to an AOT program now that sys_host.cpp calls it.
