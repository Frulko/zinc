## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done (2026-10-11). zinc debug --dap (src/dbg/dap.cpp): Content-Length framed DAP on stdin/stdout, yyjson for the requests. A reader thread answers initialize, setBreakpoints (per source path, replaced as a whole; unverified with a message when there is no code), setExceptionBreakpoints (none), configurationDone, threads, pause (Debugger::requestPause from that thread: the next statement stops) and disconnect/terminate (ends the process); the main thread compiles the program named by launch (cwd, args, stopOnEntry), answers launch, sends initialized, waits for configurationDone, runs it, and while paused answers stackTrace (absolute source paths, line and column), scopes (Locals), variables (objects' fields and arrays' first 100 elements unfold through variablesReference), evaluate of a local's name, continue/next/stepIn/stepOut; stopped events carry the reason (entry, breakpoint, step, pause) and hitBreakpointIds. The program's stdout and stderr are pipes pumped into output events (UTF-8 sequences kept whole); at exit, terminated (and a failed launch response when the program did not compile). The core gained a mutex (breakpoints and the pause request may change while the program runs; lineHot bytes are read without it), runFirst, reasons, Local raw values and children; debug builds keep absolute file paths. VS Code: lib/editor/vscode-zinc-debug (package.json contributing a 'zinc' debugger and breakpoints for typescript/typescriptreact, checked against the contribution-point docs; bin/zinc-dap runs the tree's zinc, else $ZINC, else PATH); docs/guide/01-getting-started.md Debugging gives the link command and launch.json; docs/dev-mode.md and the command table. AC1: tests/t1/debug_dap.sh with tests/dap_check.py (17 checks on main.ts, a failed launch with the diagnostic in an output event, a pause of a running loop). AC2: the guide section. Not verified: VS Code itself (not installed on this machine); the protocol follows the spec and the scripted client. usage: n/a
