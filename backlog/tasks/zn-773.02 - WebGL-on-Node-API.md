## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done (2026-10-21). src/gl/webgl_js.cpp is written against Node-API only (no JS_* left); libzn_webgl reaches the engine through a zn_napi_table (include/zn/napi_table.h: an X-macro of the 54 napi_* it and the napi_util.h helpers call, ZN_NAPI_TABLE_INIT fills one in a line) handed to zn_webgl_open(present, table); src/gl/napi_trampoline.cpp defines each napi_* as a hidden function of the module (NAPI_EXTERN= with hidden visibility). zinc's webglHook passes a table filled from zn_napi_qjs and calls install(env) (contextOf ponytail gone). nm -u build/libzn_webgl.dylib: 0 JS_*/napi_* (was 43); tests/t0/webgl_module.sh now checks it.
Design choices: classes through napi_define_class with a constructor that throws Illegal constructor unless the binding builds an instance (napi_new_instance + napi_wrap); natives told apart by a tag word (no napi_type_tag_object in QuickJS's Node-API); wrappers and extension objects kept by strong napi_refs as the JSValue dups were; the context object reached from an extension's call through a WeakRef (a strong ref would keep every context forever); the 0 ms timers (composite, task boundary, lose/restore events) go through one JS helper made at install that holds the context until it fires; function lengths kept with a define_properties of length; Float16Array (reported as bytes by the QuickJS Node-API) read by its byteLength.
Measured (load 10 to 57 from other sessions, so noisy): js-three, ZINC_HEADLESS=1 ZINC_DETERMINISTIC=1 ZINC_FRAMES=2000, 6 runs each, min: before 3.692 s wall / 2.538 s CPU, after 3.841 s / 2.477 s (within 4%). The example makes 28 WebGL calls a frame (counted with a temporary counter), so the per-call cost below is about 0.6 us of a 1.3 ms frame. Per call (200k calls, best of 5, base vs new back to back): getError 45 -> 67 ns, bindBuffer 64 -> 82, uniform4f 63 -> 85, uniformMatrix4fv 91 -> 112, bindTexture 62 -> 80, enable 52 -> 67: about +20 ns (the napi callback path plus one table call per napi_*). No engine-specific fast path added: not needed for AC 3.
Tests passed (tests/run --only, each separately): webgl_js (holds the webgl2 pages: there is no webgl2_js test), webgl_module, three, webenv_three, webenv_pixi, webenv_phaser, webenv_p5, webenv_canvas, webenv_image, webenv_canvas2d, example_js_three, webgl_conformance.
Left open: the JavaScriptCore module does not load libzn_webgl yet (it needs to fill a table from its own napi_* and call zn_webgl_open; later line).
