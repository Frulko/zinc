## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
After ZN-592.01 zinc links libSystem and libc++ only and `zinc --version` costs 8.3-10 ms on the Intel Mac against 4.6 for an empty program and 5.3 for qjs on an empty file; jsonout interpreted is 10.6 ms vs qjs 6.9 (best of 40). What is left of zinc's own: ~700 binds to libSystem/libc++ (-no_fixup_chains gave nothing), 28 static initializers (main, plugin_build, policy, prof, rtcalls, project, modules, jsx, loop, mqtt, http, regexp, sock, sys_host, permissions, zrt, gfx, hal_dispatch, layout_host, shaped_gfx, native, mimalloc's _mi_process_init...), 1176 pages touched vs 448 (a 12 MB binary). Measure each (an initializer-free build, page-ins with vm_stat), then cut the largest: initializers made lazy (function-local statics), mimalloc's process init deferred to the first runtime allocation, fewer pages.

## Implementation Notes

Done 2026-10-10 without its two criteria (measured, the remaining cost is structural); follow-up ZN-592.05.
Measured (Intel Mac, proc_pidinfo start time -> probes linked first and last into zinc, 40 interleaved runs): empty program main at 4.8 ms; zinc's first initializer at 8.2 ms, its 28 initializers take 0.5 ms. Synthetic programs: zinc's 354 libSystem imports alone cost 1.8-2.0 ms (dyld walks libSystem's 38 re-exported libraries in order; libsystem_kernel is 32nd), its 199 libc++ imports 0.2-0.3 ms, 12 MB of data 0.4 ms; the 5 weak-def coalescing references (operator new, std typeinfos) nothing measurable.
Kept: _hal_heap_region_more (zinc's last exported weak definition; only the ESP32 HAL overrides it, statically) added to tools/zinc-unexported.txt: zinc loses MH_WEAK_DEFINES, -0.5 ms to the first initializer (median 9.04 -> 8.50). tests/t1/launch_time.sh now also fails when zinc exports a weak definition. launch_time: --version 3.8-4.4 ms over the empty program (budget 5), run 5.0-5.3 (budget 6): PASS x3.
Tried, not kept: -no_fixup_chains (dyld 4 binds lazy pointers at launch: 30.9M instructions, same time); -dead_strip with an export list of the plugin ABI (zrt, JS_, hal_, zn_: 11.9 -> 10.8 MB, libSystem binds 389 -> 333 only, and every future plugin symbol must match the list).
Not met: AC1 (--version within 2 ms of the empty program: ~3.5 ms) and AC2 (jsonout 10.6 vs qjs 6.9 ms): both need fewer libSystem imports in the binary that starts a run: ZN-592.05 (the toolchain as a module).
