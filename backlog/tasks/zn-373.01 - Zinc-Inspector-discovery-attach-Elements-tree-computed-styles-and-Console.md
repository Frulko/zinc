## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
First part of ZN-373: app/inspector, a zinc:ui app that is a Chrome DevTools protocol client of plugins/devtools and zinc debug --cdp: discovery of the running programs on the local ports (/json/list of 9229, 9222 and given ports), attach over the zinc:socket WebSocket, the Elements tree (DOM.getDocument, requestChildNodes, live mutations), the selected node's computed styles and box (CSS.getComputedStyleForNode, DOM.getBoxModel), Overlay.highlightNode on hover, and the Console (Runtime.consoleAPICalled). ## Implementation Notes

Done (2026-10-11). app/inspector: model.ts (discover: /json/list on the given ports, 9229 and 9222 by default; Cdp: a zinc:socket WebSocket with calls by id and events, JSON read as dynamic values; the Elements rows, computed style lines, console lines) and main.tsx (zinc:ui solid: programs with Attach, the Elements tree read again 300 ms after DOM mutations, the selected node's computed style and box with Overlay.highlightNode, the Console; ZINC_INSPECTOR_DUMP=1 prints the views for tests).
