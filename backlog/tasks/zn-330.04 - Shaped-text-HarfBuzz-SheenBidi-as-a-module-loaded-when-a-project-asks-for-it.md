## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented the private same-build `libzn_text_module` boundary and retained static archives for AOT, app-library/Android consumers and the existing JSC/V8/Hermes modules. HarfBuzz, hb-subset, SheenBidi, layout and only the HB-dependent font-character/MSDF functions move behind the descriptor. The static graphics shape hooks, sbix decoder and core unibreak segmentation stay put. D207 supersedes D32: fallback remains on by default; explicit simple still opts out. No runtime/HAL/host-table or public plugin-format change.

The loader resolves an explicit sibling from the canonical executable path, opens RTLD_NOW|RTLD_LOCAL, validates descriptor version/size/every required callback, and stores locked NotTried/Ready/Failed with its error. It keeps the module and loader resident through host font-cache destruction. Required module calls fail centrally with a clear diagnostic and exit 1 (never silent full-TTF retention or lost glyphs; no C++ exception crossing runtime/JS callbacks). `loadModule(error)` lets the T0 exercise cached failures without exiting its process.

CLI packages and JS/development bundles carry the module and combined dependency license notice. A fused binary adds its own host-tuple module+licenses to its internal archive; the original .zapp stays portable. Only fused code can configure a cached executable module. Its expected SHA-256 comes from the embedded source manifest, never cached manifest/.checked; first use takes FileLock, checks the actual module bytes, dlopens under the lock and refuses corruption. Ordinary downloaded .zapp modules are ignored. FileLock+SHA helpers moved unchanged to tc/file.cpp to avoid dragging plugin loading into the standalone module test; failed flock now makes fd invalid.

Research supplied by coordinator: https://harfbuzz.github.io/building.html ; https://github.com/harfbuzz/harfbuzz/blob/main/CONFIG.md ; https://github.com/harfbuzz/harfbuzz/blob/main/src/meson.build ; https://man7.org/linux/man-pages/man3/dlopen.3.html . Reused existing layout interfaces and library subset/MSDF algorithms verbatim instead of moving host tables or whole asset/importer dependency graphs.
