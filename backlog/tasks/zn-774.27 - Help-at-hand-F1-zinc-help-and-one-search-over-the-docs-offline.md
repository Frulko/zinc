## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Research (links): Godot's F1 / Search Help opens the built-in class reference offline (https://docs.godotengine.org/en/stable/getting_started/introduction/learning_new_features.html); TIC-80's console 'help <function>' prints one short entry (https://github.com/nesbox/TIC-80/wiki). Takeaway kept: one short self-contained entry per name, and one search over one offline index.
Done: zinc help <name> (src/doc/help.cpp, the doc module's extractApi over lib/std modules and lib/{gfx,modules,zinc}.d.ts, as zinc doc and the cheat sheet read them): the module, the signature, the doc comment (else the reference table row of docs/reference/*.md: pointerX has no comment), one example (the comment's @example, else the first call in a code block of docs/reference, learn, start, guide) and the offline page. A command name keeps its command help; an unknown name exits 2 and points at --search. zinc help --docs [page]: the engine's docs (zinc doc --std, 0.4 s) built once into $ZINC_HOME/docs/<version>/ with a VERSION stamp, rebuilt for another version; tools/package now ships lib/*.d.ts and the published docs (site/docs-map.mjs dirs and top pages, their images) so an installed zinc builds them with no network. zinc help --search <words> / --index: the docs' own search index (lessons, pages, headings with the error codes, API) plus the CLI commands; ranking: whole title > title prefix > all words > section, pages before headings before commands before API. Atelier: F1 (Help > Help on the Name Under the Caret) prints zinc help <word> in the console (the same entry as the CLI; no word: the help box); Cmd+Shift+H opens the help box (a palette mode over zinc help --index, plugins' API left out, the lessons before a word; a page opens from the local copy, a name or command prints its help); the Help menu's pages (openDocs) open the local copy, the site when the page is not part of it (demos). Session command help:<name>.
Decision: F1 shows the entry in Atelier's console rather than a web view: Atelier has no HTML view, and the console is where zinc explain already speaks; the full page opens from the local copy.
Proof: tests/t0/help_names.sh (2 s): rrect's entry, pointerX's text from the reference, zinc help run unchanged, unknown name exit 2, --docs stamped, ten queries (gfx, Z0103, stage, a window and a shape, keyboard, text and images, rrect, onClick, doctor, explain) in the first three. An Atelier session (first, help:rrect, help-search) printed the entry in the console and opened the box; zinc check app/atelier ok.
later.md: - ZN-774.27: zinc help's own lines (Example, More) are English; translate them with the cli catalog. - ZN-774.27: the help box's ten queries are checked on the CLI ranking; an Atelier session test of the box (type a query, read the items) would check its fuzzy ranking too.
