## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
First part of ZN-590. When the display replays the command lists on the GPU (the macOS GL window, display-gl), gfx.stroke() and the map plugin record a STROKE command (the polyline, its width, closed) instead of stroke_contours' outline; the GL replay draws one box per segment and the fragment shader takes the capsule distance (round joins and caps), each pixel owned by the nearest of the segment and its neighbours; the software raster tessellates a STROKE it meets (same contours). Counters in ZINC_GL_STATS: strokes tessellated and LINE/POLY tiles rasterized on the CPU per frame.
