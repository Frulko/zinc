## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Online demos fetch resources whose sites refuse CORS (music's radio logos, map tiles). A stateless proxy (an export's serve and a small deployable script) forwards GET requests to hosts listed in zinc.json web.proxy, nothing else. Never process, fs or devices from a server.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A page's fetch to a listed CORS-blocked host succeeds through the proxy and an unlisted host is refused (test)
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
2026-11-08 (worktree agent): done.
- zinc.json targets.web.proxy: hosts ('host' any port, 'host:port', '*.domain'); targets.web.proxyUrl (default ./__proxy). The page's fetch (export only, not under zinc dev whose bridge fetches from the machine) sends GET/HEAD to a listed cross-origin host to <proxy>?url=<address> with credentials omitted; the Response keeps the original url. Every other request is the browser's own.
- serve.py: /__proxy (hosts from proxy.json): listed hosts only (403), GET/HEAD only (405), no cookies/auth forwarded (only Accept, Accept-Language, Range, If-None-Match, If-Modified-Since), redirects only to listed hosts, a host name resolving to a non-global address refused (an address listed literally is allowed: LAN devices), 32 MB cap, 20 s timeout.
- proxy.mjs (written next to the page when hosts are listed): the same proxy as a Cloudflare Worker / Deno 'export default { fetch }' with CORS headers; manual redirects re-checked (5 hops max).
- tools/web-browser-test opens an http address as well as a folder (to run a page behind serve.py).
Research: isomorphic-git cors-proxy filters by request shape, not host (https://www.npmjs.com/package/@isomorphic-git/cors-proxy); pondpilot/cors-proxy: domain allow-list, private-IP and redirect blocking, no credentials (https://gh.r-mj.com/pondpilot/cors-proxy/security); ?url= format kept (easier to validate than /https://host/path).
Proof: tests/t1/web_proxy.sh PASS (headless Chrome: a listed no-CORS site answers through serve.py, localhost not listed is refused by CORS; the proxy refuses an unlisted host, POST and file:; proxy.mjs on Node: 200, 403, 405).
Decision (for the coordinator): setting under targets.web (proxy, proxyUrl), not a top-level web.proxy. The DNS check is not pinned to the connection (rebinding between check and request not caught) and proxy.mjs has no DNS check (Workers cannot reach private networks; Deno can).
Proposed tests: music and maps/explorer exported with their hosts listed (radio logos, tiles), web_real.
