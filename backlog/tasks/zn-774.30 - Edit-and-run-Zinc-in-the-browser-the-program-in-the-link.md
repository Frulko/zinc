## Result (2026-11-09): /play/ on the site, the program in the link, no cross-origin isolation

- `site/src/pages/play/index.astro` (starts from the game template), `play/new/<template>/` (14 templates of `zinc new`; the plugin starter is left out, its example lives outside `src/`), `play/learn/<lesson>/` (15 lesson samples: the 5 that import a plugin, 06 and 17 to 20, are left out). Component `site/src/components/Play.astro`, starters `site/src/data/play.ts`, list `PlayStarters.astro`.
- Editor: CodeMirror 6 (`basicSetup`, `javascript({ typescript: true, jsx: true })`, `lintGutter`), bundled by Astro's Vite from `site/package.json` (pinned: codemirror 6.0.2, @codemirror/lang-javascript 6.2.5, @codemirror/lint 6.9.7, lz-string 1.5.0, fflate 0.8.3, all MIT, `docs/licenses.md`). One 520 KB chunk, 174 KB gzip, on the playground pages only.
- Checker: `targets/wasm/glue/compile-worker.mjs` runs `compiler.mjs` in a Worker (D242), 400 ms after the last edit. The diagnostics (`/p/<file>:line:col: error Zxxxx: ...` and the caret line) become CodeMirror diagnostics and a list under the editor; each code links to its heading of `/docs/diagnostics/` (anchors computed from docs/diagnostics.md, all 44 checked against the built page).
- The link: `#files/<lz-string compressToEncodedURIComponent of the JSON { path: text }>`, written with `history.replaceState` after each edit (as the TypeScript playground's `#code/`, but a project of several files). Reset goes back to the starter and clears the hash.
- Run: `vm-web.wasm` in a Worker on an OffscreenCanvas sized from `zinc.json` `app.window` (640x400 by default). **JSPI is done here** (`targets/wasm/glue/worker.mjs`): with no SharedArrayBuffer in the start message, `zn.gfx` is a `WebAssembly.Suspending` import that returns a promise for `host.gfxPoll` only (resolved on the worker's next `requestAnimationFrame`), `zn_run` goes through `WebAssembly.promising`, the page posts the input as messages. The SharedArrayBuffer path is unchanged for `glue/index.html`. The page needs no COOP/COEP (GitHub Pages cannot send them); without `WebAssembly.Suspending` Run is disabled with a sentence (Chrome or Edge 137+), the checker and Export still work. Rows with nothing to report in the browser (paused, idle hint, wheel, touch, key and command queues...) now answer 0 silently; the ones that draw and are missing are named in the status line ("Not drawn in the browser yet: Border, Clip").
- Export as project: `sketch.zip` (fflate `zipSync`), one folder `sketch/` with the files and a zinc.json (the project's own when it has one); `zinc run sketch` opens it.
- Lesson pages: an "Edit and run" button (string `learn.edit` in the five languages) beside "Run it here" puts `/play/learn/<lesson>/?embed` in a frame in the picture's place (`?embed` hides the site's header and footer).
- Engine files: `site/play-engine.mjs` (run by the `assets` script before dev and build) copies `build-wasm/zinc-compile.wasm`, `vm-web.wasm`, the glue and writes `std.json` (lib/std + targets/capabilities.json, 1.47 MB raw) into `site/public/wasm/` (git-ignored). `.github/workflows/pages.yml` installs zig 0.15.2 (`mlugg/setup-zig@v2`) and runs `tools/build-wasm compiler` and `tools/build-wasm` before the site build (not run here: it runs on a release).
- Engine gap fixed: the wasm compiler did not read the project's zinc.json, so a template asking for system permissions (desktop-app: menu, tray) got Z5006. `targets/wasm/compile_main.cpp` now reads it as `loadManifestPermissions` does (permissions for `$ZINC_PLATFORM`, default web; app and scopes JSON). The compiler grew 3,503,191 -> 3,599,546 bytes. `wasm_compiler` still byte for byte.

### What runs in the page today (headless Chrome 157, non-isolated)
- Templates: game, stage, cli and iot run (cli and iot print and end); server and service compile and stop at `net.serve` (no network rows in the browser); 3d (npm `three`), canvas, eink, game-2d, iot-board, remarkable (plugins), dashboard and desktop-app (`zinc:svg` through lib/std/icons.tsx, and no lucide icon table) stop at the checker with their Z0119, which names the module. Their page says which plugin they use.
- Lessons 01-05 and 07-16 compile (30 ms for a drawing, 300 ms for a zinc:ui one) and run; 13-16 draw without transforms and clips, 09-12 without borders, shadows, strokes and clips (rows the glue lacks).

### Decisions (for the coordinator's log)
- JSPI in `worker.mjs`, not Asyncify: no C++ change, no size change, the page needs no isolation; the SAB path stays for isolated pages; no Asyncify fallback (Firefox and Safari: Run disabled with the reason, check and export still work).
- The program in the hash as lz-string of a JSON file map (`#files/`), one format for one or many files. Links of a few KB; ZN-774.31 (share) can add a size warning.
- English-only playground pages, like the examples gallery; the lesson button is translated.
- Engine files built in the Pages workflow and git-ignored, not committed under site/public (4 MB of binaries per refresh).
- Lessons that import a plugin get no playground page until the browser compiler has plugins.

### Research (sonnet sub-agent)
- TypeScript playground: `#code/<lz-string compressToEncodedURIComponent>`, settings in the query, https://www.typescriptlang.org/_playground-handbook/url-structure.html; its vendored lz-string: https://github.com/microsoft/TypeScript-Website/blob/v2/packages/sandbox/src/index.ts
- Vue SFC playground: the store serialised into the hash with fflate and base64, https://github.com/vuejs/repl
- Go playground: snippets on a server (`/share`, 64 KB cap), https://go.googlesource.com/playground/+/refs/heads/master/share.go. DartPad and StackBlitz/vite.new keep projects on a server (gists, project ids) with a download: heavier than a static site needs.
- CodeMirror lint API (`setDiagnostics`, `renderMessage`, `lintGutter`): https://codemirror.net/docs/ref/#lint; versions from the npm registry: https://registry.npmjs.org/codemirror/latest, https://registry.npmjs.org/@codemirror/lint/latest, https://registry.npmjs.org/@codemirror/lang-javascript/latest, https://registry.npmjs.org/lz-string/latest, https://registry.npmjs.org/fflate/latest. Bundle with the site's Vite rather than esm.sh (no CDN at run time, one @codemirror/state).
- JSPI: https://v8.dev/blog/jspi-newapi, https://developer.mozilla.org/docs/WebAssembly/Reference/JavaScript_interface/Suspending; Safari: https://bugs.webkit.org/show_bug.cgi?id=283054. Feature test `typeof WebAssembly.Suspending === 'function'`.
- Zip in the browser: fflate `zipSync` + a Blob link rather than a hand-written zip writer.
