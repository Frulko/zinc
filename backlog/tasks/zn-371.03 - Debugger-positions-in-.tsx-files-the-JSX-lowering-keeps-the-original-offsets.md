## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Part of ZN-371: JSX is lowered to TS text before parsing (src/frontend/jsx.cpp), so the AST positions of a .tsx file point into the lowered text. Keep a map from the lowered offsets to the original ones and give the debugger (and the diagnostics) the original line and column.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done (2026-10-11). src/frontend/jsx.cpp: during lowerJsx the Lowering marks where each copy of the source begins (rw() and the top-level loop: \x01Z<offset>C) and where an element's generated code begins (lower(): ...G, also after each copy); unmark() takes the markers out, adds line breaks where the lowered text is behind the source line of the next piece (generated code has none of its own; the old padding at the end of each element is gone), and returns the pieces (SrcPiece: out offset, source offset, copy or generated) in SourceFile::map with SourceFile::original. sourceOffset/loweredOffset (ast.h) map both ways; diagnostics of the earlier passes of the same file are moved into the lowered text so formatDiag maps every diagnostic of a .tsx file back to the original line and column. Two tests on the lowered text read through the markers (an attribute literal true/false/number, the percent template of width/height): bare() strips them there; without it nuxt-ui's bytecode changed (_num became _dynNum). main.cpp maps the debug line table and gives the debugger the original text; arrow functions show as <anonymous> (lambdaN), lambdaN:name as name. AC1: tests/t1/debug_cli.sh, app.tsx session (golden tsx.out): breakpoints on line 14 (inside an IIFE in a JSX child) and 21 (after the JSX) stop there, the stack shows lines 14, 12, 12, 11, 20, step to 15. AC2: bad.tsx reports 7:8 (was 5:123). Bytecode of 252 compiling .tsx files (examples, tests, lib/std, templates) byte-identical to before; tests checker, diagnostics, jsx, jsx_style (now compares the lowered text without line breaks), lsp, debug_cli, debug_dap pass. Not done: the passes before JSX (StyleSheet, React Native imports, requireNative) keep lines but not columns. usage: n/a
