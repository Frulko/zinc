## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Pre-task research (2026-11-09, read only; no claim or implementation):

- Code/editor provider: `plugins/editor/view.tsx` CodeView and CodeEditor; EditorState, cached Doc, cursors and tokenize/langNamed live beside it. Inspect Atelier, zed-editor, Discord CodeBlock/CodeInsert plus stepCode. Reuse the kit CopyButton instead of copying Discord timers. Add missing instance options to the provider; its theme/assist/edit/decorations currently have globals, so avoid cross-editor interference. Existing languages are TS/JS/TSX, JSON, Markdown and CSS; other labels use plain text.
- Markdown: `lib/std/markdown-view.tsx` provides selectable Markdown/RichText; `plugins/markdown/index.ts` already binds vendored md4c 0.6.0 with URLs, fences, tables, task state and offsets (consumer `app/markdown`). Reuse it rather than inventing another parser. Its declared targets are narrower than editor's: inspect actual module/capability loading so unused kit imports never pull an unavailable plugin into an unrelated app.
- Diff: no shared text-diff provider found. Reuse highlighting, decorations and virtual rows; cache by inputs, bound worst-case work, avoid an unbounded LCS matrix. Release retained input/cache state on disposal.
- JSON: reuse/extract the inspector's JLine/jsonLines/JsonTree in `app/inspector/table.tsx` and counted containers in network.tsx. JSON.parse already uses yyjson. Replace shared folds with instance state; stable escaped paths, primitive roots, visible errors, counts and keyboard disclosure are needed.
- CUI reference options: language/title/gutter/emphasized lines/height; editor read-only/placeholder/indentation/find/go-to-line; split/inline diff, responsive fallback/context folds/change navigation; compact Markdown with link/task callbacks; JSON expansion depth and height. Primary sources: https://github.com/yappologistic/CUI/blob/master/include/cui/cui.h, https://github.com/yappologistic/CUI/blob/master/docs/components-more.md#code, https://github.com/yappologistic/CUI/blob/master/src/cui_code.c, https://github.com/yappologistic/CUI/blob/master/src/cui_diff.c.
- No engine gap was confirmed by reading. Runtime parity, keyboard behavior and size remain unproved. Use the coordinated canonical kit host bridge from ZN-1095 and the existing Quiet/reduced-motion helpers; do not copy infrastructure into a showcase.
