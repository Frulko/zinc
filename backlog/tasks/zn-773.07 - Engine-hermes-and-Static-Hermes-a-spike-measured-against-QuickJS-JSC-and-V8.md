## Implementation Notes

Done on the M1 Pro, 2026-10-21 (load 11 to 18).
- tools/hermes-pack: facebook/hermes static_h at e760a68ab717963f82757983c75ec7fd63910d77 (pinned in the script), built from source with CMake (Makefiles; Ninja when installed) at -j4 into ~/.zinc/sdk/hermes/<commit> (include/, lib/libhermesvm.dylib with its Node-API, bin/shermes, hermesc, hermes), current symlink; sources and build beside it. tools/hermes-patches/zinc-embed.patch: four C entry points in libhermesvm (zn_hermes_create/drain/run/run_unit) and the Promise polyfill's rejection tracker told at once (enable({onReject, onHandle})) instead of after a 2 s timer.
- src/engine/hermes.cpp + zn_engine_hermes (CMakeLists.txt, guarded on ZN_HERMES_DIR): microtasks through Runtime::drainJobs, unhandled rejections as v8.cpp (told at once, reported after the drain), one handle scope open for the run (without it Hermes's env marks no slot: hero crashed in the first young GC), no inspector (ZINC_INSPECT says so), no WebAssembly. ZINC_HERMES_JIT=0, ZINC_HERMES_OPT=1 switches. src/engine/hermes.h gives the bindings the named napi_run_script. --engine hermes accepted in main.cpp, cli_core.cpp (help, zinc.json, export, dev), test_cmd.cpp; tools/engine-pack hermes (upstream = the commit from ZN_HERMES_DIR): 1.8 MB pack, runs through ZINC_ENGINE_HERMES.
- Runs: tests/t0/hermes.sh (jsc.sh hermes, all checks), native_callbacks.ts (qjs_native.sh loops over hermes), hero 600 frames, js-three (WebGL), js-pixi, js-phaser, js-p5, js-gsap, js-anatomy: frame 30/60 pixel-identical to QuickJS. lib/std/webenv.js: import() of module scripts through new Function (Hermes has no import() syntax and its lazy compile made runScript a parse error).
- Static Hermes (#2): tools/hermes-unit bundles a program (zinc bundle --engine hermes), compiles it with shermes -O -c -exported-unit=zinc_bundle, links a dylib against libhermesvm; ZINC_HERMES_UNIT=<dylib> makes the module run that native unit in place of the bundle's source, same Runtime and Node-API env. Hero runs that way, frame 30 identical to QuickJS.
- Numbers (#3): docs/reports/zinc-next-perf.md 'Hermes and Static Hermes beside the three engines'; verdict in docs/reports/hermes-engine.md 'Measured verdict': Hermes kept as an experimental engine for source builds, no pack published; Static Hermes kept as a tool. Driver: u8[]/f64[] arguments copied with new T(n).set(a) on Hermes (ZN_ENGINE_HERMES): image_upload_only 25.1 -> 3.3 ms.
