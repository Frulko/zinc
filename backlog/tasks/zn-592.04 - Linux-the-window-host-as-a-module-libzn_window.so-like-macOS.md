## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implementation: GNU desktop window module defaults on; musl and AOT remain static. SDL PIC/full archive is confined to libzn_window.so. Mach-O frameworks and flags stay Apple-only. Linux plugins retry unresolved SDL symbols after the module loads; SDL headers/pkg-config bypass are used only for declared Linux SDL consumers. Package copies the module and scans its transitive dependencies, with ../lib relative paths. Fuse selects the host suffix and validates cached bytes against SHA-256 of its embedded payload, under flock and atomic rename, then rechecks before dlopen. Loader lifecycle is explicit and locked, including constructor reentry and sticky failure.

Research supplied by coordinator and verified during work: https://man7.org/linux/man-pages/man3/dlopen.3.html ; https://sourceware.org/binutils/docs/ld/Options.html ; https://wiki.libsdl.org/SDL3/README-cmake . Pinned Zig 0.15.2 rejects -Bsymbolic-functions (https://github.com/ziglang/zig/issues/18804). Chosen equivalent for its module boundary: protected function declarations generated from existing signatures/list; shared runtime data remain default undefined imports. Other native ELF linkers retain -Bsymbolic-functions. No blanket -Bsymbolic. Details: docs/reports/zinc-linux-window-module.md.

Proof: own x86_64 GNU Linux cross build passed via tools/build-linux --arch x86_64 --no-package (all heavy commands queued/bounded by work-run). .logs/linux-build.log is the initial rejected-linker-flag attempt; .logs/linux-rebuild.log is the successful final build. Exact tests/run --only window_module passed (real loader, reentry, shared data, two-thread access, explicit missing override, real fused extraction same-size corruption/concurrent repair, actual ELF exports/dependencies). .logs/window-module-t0-final.log, .logs/t0/window_module.log if produced by runner, .logs/*symbols.txt and *dynamic.txt, .logs/provenance.json preserve proof.
