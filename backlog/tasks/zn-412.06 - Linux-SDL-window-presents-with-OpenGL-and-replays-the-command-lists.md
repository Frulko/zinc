## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ZN-412.02 turned the GL window on for macOS only (targets/macos/hal_sdl.cpp, ZN_HAL_GL, OpenGL.framework). Linux keeps SDL_Renderer and the software raster. A GL path there needs a loader: zinc carrying glad while the WebGL module carries its own could interpose on Linux (zinc exports its symbols), so either the module and the window share one glad, or the window loads through SDL_GL_GetProcAddress into its own table. llvmpipe stays on the software raster (auto).
