## Implementation Notes

2026-10-30, worked in a parallel worktree. Done: criteria 1, 3, 4; criterion 2 all but its last clause.
Format (decision, reversible): a lesson is learn/lessons/<id>/ shipped with the engine (tools/package copies it to share/zinc/learn/lessons): lesson.json (title, the docs/learn page it exercises, the edited file, per step its text, the one message of its check and a hint, each in en/fr/es/it/de), the project's zinc.json and assets, and per step steps/N.start.ts, N.check.ts (a Zinc program given the edited file: exit 0 when done) and N.solution.ts. Five lessons, three steps each: 01 window-and-shape, 02 colours-and-movement, 03 keyboard, 04 mouse-and-touch, 05 text-and-images. The check runs zinc check first (a program that does not compile shows its diagnostics), then the step's check with zinc run --interp (about 0.1 s). Checks read the source (regex), not the running program: simple and offline; a check that runs the program headless is a later.md line.
CLI: src/cli_learn.cpp, zinc learn [lesson] [--dir] [--check|--hint|--solve|--unpack] [--json] [--reset]: unpacks into ./<id>, watches the file, re-checks on save, Enter/h/s/q at a terminal; progress in $ZINC_HOME/learn.json; no network.
Atelier: app/atelier/app/lesson.ts + components/Lesson.tsx: Help > Lessons opens a lesson (unpacked in the sketchbook) with a side panel beside the editor (title, step n of N, text, verdict, Check, Hint, Solution which writes the solution into the editor and saves, Read the lesson); each save checks the step; the progress is the CLI's file (kept locally). A lesson folder opened later gets its panel back.
