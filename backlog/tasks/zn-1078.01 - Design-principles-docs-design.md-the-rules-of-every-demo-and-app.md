Research (sonnet sub-agent, from memory, not re-fetched; check before quoting figures):
- shadcn/ui neutral (ui.shadcn.com/docs/theming): background 1, foreground 0.145, border 0.922, muted-foreground 0.556 (oklch); dark border white/10%; focus ring-[3px] ring-ring/50.
- Radix Colors 12-step scale (radix-ui.com/colors/docs/palette-composition/understanding-the-scale): 1-2 backgrounds, 3-5 element fills, 6-8 borders and focus, 9-10 solid, 11-12 text. Our Quiet greys follow CUI's OKLab steps instead.
- Apple HIG materials: elevation by lightness in dark mode, shadows/materials only on floating layers, hairline separators.
- Springs: SwiftUI/WWDC23 duration+bounce (zeta = 1 - bounce), the model CUI uses; React Spring default 170/26 is near critical. Closed form step (ryanjuckett.com/damped-springs) is stable at any dt.
- Reduced motion (web.dev/articles/prefers-reduced-motion): keep feedback, replace moves by a cut or a short fade.

Later.md line (engine gap found): a JSX child that is a variable holding an array of nodes ({dots} with dots: i32[]) renders as the text '17,18,...' instead of the nodes; .map(...) inline works. React renders arrays of elements, so a program written as in React breaks.
