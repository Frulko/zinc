## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
First part of ZN-562. The WebGL1 calls a textured, lit cube needs (shaders, programs, buffers, attributes, uniforms, textures, drawElements, clear, enable, viewport, depth) as host rows of the runtime table, called by a typed module zinc:gl (a WebGLRenderingContext-like class, WebGL objects as typed handles, the constants). The rows go to libzn_webgl's WebGL1 class (src/gl): the interpreter loads the module beside zinc as QuickJS does, an AOT program links zn_gl statically. The context draws offscreen and presents into a zinc:gfx image (the asynchronous read of ZN-411). Example examples/gl-cube.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-10-10. 44 host rows host.gl* appended to the runtime table (isGlRow, routed to zn::host::hostGl; not system rows, never release); lib/std/gl.ts is zinc:gl: createContext(w, h, version), a WebGLRenderingContext class over the rows (the 292 WebGL 1.0 constants as getters: a class holds at most 255 fields), typed handles, Float32Array / Uint16Array / Uint8Array wrapping Zinc arrays, present(image) into a zinc:gfx image. src/gl/webgl_host.cpp (in libzn_webgl and zn_gl) serves the rows with the WebGL1 class (same validation as QuickJS); zinc loads libzn_webgl at the first gl row (main.cpp glRows, the loader shared with the QuickJS hook); an AOT program that calls the rows links zn_gl, glad and glslang and its main calls installGl (src/gl/webgl_install.cpp); the present hooks moved to src/host/gfx_host.cpp (glPresentHooks). present() reads synchronously for now (the ZN-411 pipelined read: ZN-562.03).
AC1: examples/gl-cube draws the textured, lit cube interpreted and built (GL 3.3 core on macOS); the vc4 / GLES2 part is ZN-562.04.
AC2: tests/t1/gl_cube.sh: interpreter and AOT frame hashes equal (pixel-identical), the cube is drawn.
AC3: same test: bouncing-ball interpreted does not load libzn_webgl (DYLD_PRINT_LIBRARIES), built it has no WebGL/glad symbol (the checks do catch gl-cube: 1 load, 532 symbols).
