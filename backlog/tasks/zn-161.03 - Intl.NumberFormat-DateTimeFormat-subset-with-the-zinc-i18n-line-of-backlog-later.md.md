Implementation

- A shared typed validation/prelude supplies NumberFormat/DateTimeFormat, format/resolvedOptions/supportedLocalesOf and legacy locale methods. tools/gen-intl creates the checked-in JavaScript copy with the pinned esbuild; native Intl constructors and locale prototypes are preserved.
- Stateless appended host rows use dynamically loaded CoreFoundation on macOS, with RAII for every locale/zone/formatter/string. No ICU4C, native handle registry, formatter cache, process-TZ mutation or replacement of zinc:i18n catalogs.
- Portable hosts provide the documented en-US/en decimal and UTC Gregorian subset. portablePattern is the single pattern for portable formatting and resolved field widths; the native self-check directly exercises portableDate, decimal rounding and malformed locale handling. Platform UTC calendar limits fail clearly.
- Bound format callbacks capture primitive/immutable settings rather than their formatter. Empty, null and omitted locale/zone values remain distinct. Receiver and argument expressions retain left-to-right order; Date reads its time after argument expressions but before option getters.
- Three necessary shared frontend repairs: lazy conditional initialization for default closure parameters (including Dyn), inferred Dyn-array element conversion after inference (either element order, no extra evaluation), and lazy public getter reads in typed-to-Dyn views. Setter/own-key/clone restrictions, collection snapshots and bytecode layout are unchanged.
- PhotoSorter now uses its natural locale date call; both manual month arrays and its workaround comment are removed. French day one follows Intl's numeric day instead of the former app-specific 1er.
