2026-11-12 software completion (work/535-lazy; supersedes the software handover above): zinc:platform now exposes the requested runtime observations through an explicit generated-module export-group contract. A shared metadata catalog names the group, its private profile/full variants and zinc:board dependency. Named value imports/re-exports requesting a member, namespace imports and star re-exports select the full eager group; profile-only and bare imports retain the profile source without the board dependency. The snapshot evaluates once before the requesting importer, not retroactively before earlier profile-only importers. Direct zinc:board shares its state. This changes generated-module resolution only, not ordinary TypeScript barrel effects. Neither sysDevice nor JSON.parse is marked pure and no build-host values are baked into binaries. Full contract in docs/reports/zinc-next-board.md.

QuickJS and its bundler share the same catalog/selector. Plain JS static declarations are lexed independently of the typed parser (quoted import names and surrounding native JS grammar are preserved).
