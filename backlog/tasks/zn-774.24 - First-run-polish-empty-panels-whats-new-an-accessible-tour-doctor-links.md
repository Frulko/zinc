## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Research (links): NN/g empty states, status + a learning cue + one direct action (https://www.nngroup.com/articles/empty-state-interface-design/); WAI-ARIA APG modal dialog, focus moves in, Esc closes, focus returns to the opener (https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). VS Code's update.showReleaseNotes could not be confirmed from its docs (setting name unverified).
Done: (1) the editor's empty pane: no sketch -> one sentence and the button Examples and templates; a sketch with no open file -> one sentence and Add a file (the shortcuts stay below); the empty console keeps its sentence and gets one Run button. Atelier has no separate problems or recent-files panel: problems are the status line ('No problems'), the recent sketches are the start view. (2) components/WhatsNew.tsx: at start, when `zinc version` differs from the version seen last (marker file, beside the tour's; a first launch only remembers it), a non-modal card in the corner with this version's CHANGELOG.md lines (8 lines, 120 characters each, the rest in zinc changelog); 'Don't show again' sets whatsNew: false; Help > What's New shows it any time. zinc changelog [version] prints the section (a dev build: Unreleased); tools/package ships CHANGELOG.md. (3) the tour's buttons (Next, Back, Skip, Fix, the lessons) are Buttons: Tab, Enter and Space; the main button takes the focus at each step, the editor gets it back when the tour ends; Escape already skipped; Tween and Spring land at once under ui.prefersReducedMotion(). (4) zinc doctor: a row that is not ready (the engine missing, an update, Xcode tools) prints 'How to fix it:' and a link to docs/guide/01-getting-started.md#<anchor> for this OS (new section 'When zinc doctor reports a problem', one heading per row and OS).
Proof: tests/t0/doctor_links.sh (every anchor is a heading slug, the missing-engine row links, zinc changelog 0.11.5, an unknown version fails); doctor_friendly and help_names pass; Atelier sessions: the What's new card in German (seenVersion 0.0.0), the tour card in German with its buttons, zinc check app/atelier ok.
Not proven here: the keyboard path of the tour (Tab/Enter in a session), the German text of every tour step (one checked), reduced motion (no way to set it in a headless session).
Proposed tests: an Atelier session that drives the tour with keys (ZINC_INPUT key events) and dumps every step in German to check no text is clipped; tests/t1/atelier_tour.sh and atelier_styles.sh (Buttons in the tour).
later.md: - ZN-774.24: Atelier's What's new card shows the English CHANGELOG lines; translated release notes would need a per-language changelog. - ZN-774.24: docs/i18n/*/guide/01-getting-started.md are now stale (the doctor section).
