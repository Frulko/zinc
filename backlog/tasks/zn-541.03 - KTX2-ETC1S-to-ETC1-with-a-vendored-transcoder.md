## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented only this split's native KTX2 criterion and its T3/T4 no-op seam; parent ZN-541 remains open for actual Pi, FPS and prerequisites 538/540. Existing material/static merge/split/warm-up work retained.

API: createKTX2Loader(renderer, ordinaryLoader) is synchronous. T3/T4 return that exact object. T2 creates a Loader-derived adapter, lazily importing the private native spec on decode. Loader's manager/path/headers/credentials and loadAsync are reused; parse(buffer,onLoad,onError), detectSupport, load and dispose work with actual r162/r186 GLTFLoader's embedded Blob URL path. FileLoader owns transport progress; a balanced extra manager item covers decode, including synchronous transport throws. No handles, persistent transcoder registry, workers, WASM or engine changes.

Native: call-local ktx2_transcoder and source lifetime through every mip; ETC1S ordinary 2D only, get_layers()==0, one face, no depth/video/other codecs. Input <=64 MiB, sides <=4096, legal mip count, decoded total <=128 MiB, per-level capacity checked before allocation. Incomplete pyramids are accepted with non-mip filtering. Opaque output is ETC1 if renderer supports it, otherwise RGBA32; alpha always RGBA32. DFD transfer/primaries/flags retained; no native second premultiplication. Bytes return through the existing native large typed-result path instead of plain out-array writeback; a 66,564-byte regression covers it. Both Basis init and immortal module construction use guarded static initialization: -fthreadsafe-statics explicitly overrides plugin compiler default -fno-threadsafe-statics; final DSO has __cxa_guard_acquire/release. Factory does not write rc after initialization.

Research verification: official r162 KTX2Loader and pinned Basis header confirm Loader/texture metadata and transcoder capacity/lifetime API. Links: https://github.com/mrdoob/three.js/blob/r162/examples/jsm/loaders/KTX2Loader.js ; https://github.com/mrdoob/three.js/blob/r186/docs/pages/GLTFLoader.html ; https://github.com/BinomialLLC/basis_universal/blob/9bebe16726b3a61c8c213eeee3b7cffb462ef34e/transcoder/basisu_transcoder.h ; https://github.khronos.org/KTX-Specification/ktxspec.v2.html . Reuse existing Basis Universal 2.50 Apache-2.0 vendor (PIN 9bebe16726b3a61c8c213eeee3b7cffb462ef34e), disable KTX2 Zstd, retain upstream -fno-strict-aliasing. tools/package copies its existing transcoder/LICENSE/NOTICE/PIN/checksums once for native source rebuilds; no second vendor. Actual selected package statement passed all 28 SHA256SUMS entries and PIN equality without a full package run.
