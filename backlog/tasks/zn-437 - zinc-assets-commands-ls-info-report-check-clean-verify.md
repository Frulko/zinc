Done 2026-11-09 (worktree agent). zinc assets check / report [--diff] / clean in src/cli_core.cpp; zn::assets::readReport, cleanCache, humanSize in src/assets (lint now uses humanSize instead of its own copy). Sizes come from the report.json the build writes, read back per group: nothing is measured twice. zinc export copies build/assets/<target>/report.json beside sbom.spdx.json.

Decisions: check builds the release packs (what ships) for --target (default this machine), then reads report.json. Budget meaning: download and flash = every pack together; boot = groups of loading.groups, else boot, each counting max(pack bytes, decoded bytes) (a compressed pack is decoded, the splash is mapped as is); ram and gpu = each group alone (a group is loaded whole and zinc:assets refuses one over the ram budget), so streaming games are not failed by their total. Sizes in KB/MB with KB = 1024 B, the convention zinc.json budgets already parse. report --diff: groups sorted by the largest pack change, new and removed groups said, unchanged ones listed, a total line, exit 0 (informational). clean: remove_all of ~/.zinc/cache/assets (a build running meanwhile re-imports a missing artifact, as after a trim). ls and verify cut, as the 2026-10-25 review said.

Research (sonnet sub-agent): size-limit https://github.com/ai/size-limit (limit string per entry, custom message, headroom advice); bundlesize https://github.com/siddharthkp/bundlesize (maxSize per path, compression); webpack performance budgets https://webpack.js.org/configuration/performance/ (per asset and per entry budgets, hints error/warning, names the largest modules); Lighthouse budgets https://web.dev/articles/use-lighthouse-for-performance-budgets (budget.json, a total resource type); bloaty diff https://github.com/google/bloaty/blob/main/doc/using.md (signed deltas and percent, largest growth first, TOTAL row). Taken: one line per violation with size, budget and excess; signed deltas with percent; largest change first; total row; new/removed groups explicit; exit 0 pass, 1 over, 2 usage.
