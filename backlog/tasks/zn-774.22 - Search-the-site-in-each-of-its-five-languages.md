## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Research (links): Pagefind multilingual, one index per <html lang> automatically (https://pagefind.app/docs/multilingual/); Component UI, new in 1.5, a modal trigger whose shortcut attribute sets the key, Esc closes, strings translated from the page language (https://pagefind.app/llms-component-ui.txt); Node API indexes only, no search from Node (https://pagefind.app/docs/node-api/); Starlight wires Pagefind by default (https://starlight.astro.build/guides/site-search/).
Decisions: pagefind pinned 1.5.2 as a devDependency of the site (MIT; 1.6.0 was one week old); not vendored in third_party (a site build tool, like astro). The search box is Pagefind's Component UI (<pagefind-modal-trigger shortcut="/"> + <pagefind-modal>, bundle path set by <pagefind-config>), coloured with the site's tokens. Index: <main data-pagefind-body>, the docs sidebar, the untranslated/stale notices and the edit link ignored. Ranking: { termFrequency: 0 } (site/search.json, given to the box by Base.astro and to the check): with Pagefind's default, short pages that repeat a name (examples, guides) beat its reference page (onClick, pointerX); weights on reference pages alone (3, even 10) did not change it. Reference pages weigh 3 (DocPage article).
How the check searches from Node: site/search-check.mjs imports the browser's dist/pagefind/pagefind.js with fetch answered from dist and a stub document whose html lang is the language; one module instance per language.
Proof: pnpm build = astro build + pagefind (733 pages, 5 languages, 1.5 s for the index); node search-check.mjs 50 of 50; headless Chrome on /zinc/fr/docs/learn/: '/' opens the dialog with the focus in the input (French strings), 'gfx' lists zinc:gfx reference first, Esc closes; check-links 0 broken. tests/t1/site_search.sh (8 s) passes; pages.yml runs search-check after the build.
later.md: - ZN-774.22: the search box only exists after pnpm build (astro dev has no index); a dev fallback message, and the search box's dark-theme border-focus colour (--pf-outline-focus) could follow the site's accent.
