Engine findings (taught the way that works):
- stroke() start cap: in a 640x400 surface, `clear(0xffffff); stroke([380, 100, 460, 160, 540, 120], 12, 0x5746e0, 255, false)` draws a visibly larger blob at the first point than the same polyline at y 250 (`[380, 250, 460, 310, 540, 270]`); two-point strokes at the same places are fine (headless, software raster). Seen in lesson 4's screenshot (the second line's start).
- A Button without a bg-* class paints a dark slate box (the default look), surprising on a light page: lesson 12 gives every Button a background.
- zinc.json `app.window` (the window size) requires `app.id` ("app.id is required"): every sample carries an id only to set its size.
- An arrow key handled in ui.onKey without preventDefault() also moves the focus (documented order): lesson 9 teaches preventDefault.
