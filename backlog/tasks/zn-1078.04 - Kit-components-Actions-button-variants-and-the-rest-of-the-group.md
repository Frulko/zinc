## Implementation notes

- Research: [CUI Actions](https://github.com/yappologistic/CUI/blob/master/docs/components.md), [additional components](https://github.com/yappologistic/CUI/blob/master/docs/components-more.md), [design](https://github.com/yappologistic/CUI/blob/master/docs/design.md), [WAI button](https://www.w3.org/WAI/ARIA/apg/patterns/button/), [menu button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/). Reused Button, Tooltip, DropdownMenu, ContextMenu, Dialog, engine focus scopes and kit springs; no dependency added. Existing callers remain compatible.
- Added the Actions family, index exports, disabled/loading/link button options, named icon tooltips, button/split groups, independent/exclusive toggles, segmented views, in-place clipboard feedback, cancellable hold and fuzzy command search. ContextMenu gains ContextMenu-key/Shift+F10 opening; dropdown items support checked/separator/destructive states. Gallery uses Quiet, sentence-case sections, declared icons and no decorative upload loop. Documentation pictures are drawn by Zinc. IconButton reuses Button label-color selection, so ghost, filled and destructive icons retain contrast in dark/custom/adaptive themes.
- Hold lifecycle is Idle → Holding → Confirmed through one transition function. Early release, Escape, pointer cancel/leave, local/window focus loss, background and disposal cancel its engine-clock alarm; callbacks validate node generation. Shared host cleanup works under Solid and React. Reduced motion retains hold time and feedback while cutting its spring.
- AC1 proof: gallery `zinc check` passes; `tests/run --only kit_actions` passes interpreter and QuickJS. Checks include early release, exactly-once hold, blur/window-focus/disposal cancellation, reduced-motion path, disabled focus, segmented selection/focus, toggle wrapping/exclusive selection, filtered keyboard command selection, repeated-filter row identity and keyboard context menu. Ranking uses ui.moveChild within the original map fragment, so searches do not duplicate or reparent rows.
- AC2 proof: `GALLERY=actions` and `GALLERY=palette`, `ZINC_HEADLESS=1 ZINC_FRAMES=40 ZINC_SCALE=1`, QuickJS captures at `docs/img/kit-actions.png` and `docs/img/kit-command-palette.png`; both inspected. Final dark App chrome capture also verifies the shared icon provider; kit_actions rerun passes after that color fix. Original block-bodied palette map is preserved. ZN-1079 fixed its engine node-provenance gap; the palette now draws Save document / Export PDF, rather than numeric handles.
- AC3 proof: `ZINC_ROOT=$PWD ZINC=<1079-jsx>/build/zinc timeout 40 tests/run --only kit_size` passed with the isolated Actions source state (App chrome module/export and shared .05 changes absent). No budget increased, no suite run.
- Maintainer engine lead: `try { throw new Error('copy'); } catch (e) { console.log(String(e)); }` reports Z0005, “String() of 'Error'”. CopyButton's callback promises a message, so `e.message` is its intended value; no coercion helper added. Generic Error coercion is left to the coordinator.
