## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-10-22 (parallel worktree).
- zinc:i18n (lib/std/i18n.ts, pure Zinc, registered in src/frontend/modules.cpp): language() = ZINC_LANG, then lang of $ZINC_HOME/config.json, then locale() of zinc:sys, then en (normalize: fr_FR.UTF-8 -> fr-FR, C/POSIX ignored); load(area, lang) tries the full tag, then the base language, else English; Catalog.t(key, params) / n(key, count, params) with CLDR one/many/other for en fr es it de, {{ }} escapes, English then the key itself as fallback; saveLanguage() keeps the other keys of config.json and refuses a file that is not a JSON object. Catalogs are found at ZINC_I18N_DIR or lib/std/../../i18n (import.meta.dirname is fixed at compile time, so the checkout, share/zinc of a package and the dev bundle all work). Test: tests/t0/zinc_i18n.sh (PASS).
- Atelier: app/text.ts holds the catalog in a signal, so Tools > Language (radio items) switches every text and rebuilds the desktop menu at once, and writes lang to config.json. 302 keys in i18n/<lang>/atelier.json for en fr es it de (menu, cmd.<id>, status, run, console, palette, find, editor, devices, project, permissions, example titles). App and Window menus are built with labelled role items, so About/Hide/Quit/Minimize are translated too. model.ts now returns permission words as keys (permissionWords) and app/project.ts translates them.
- Zinc children: run, dev, check, explain, new and export get ZINC_LANG=<Atelier's language>; the others (plugins, device, update, build steps whose output Atelier parses) get ZINC_LANG=en.
- Script verb lang:<code> for scripted sessions. Packaging: tools/package copies i18n/ to share/zinc/i18n; the dev bundle of package-macos.sh reads the checkout's i18n/.
- Proof: tests/t1/atelier_languages.sh (PASS): starts in German, switches to en, fr, es, it; the menu bar (recording simulator log) and the start view (scene dump) show no English word that is not that language's own word; config.json keeps welcomed. Start views looked at in de, fr, it: correct, accents drawn. atelier, atelier_ide, atelier_devices still PASS.
- Not done here: the example programs themselves draw English words (Hello, Text, Less/More), so three thumbnails stay English; tests/run does not pin ZINC_LANG=en yet (the CLI side of D159).
- For backlog/later.md: (1) tests/run should set ZINC_LANG=en so a saved lang does not change English expectations; (2) Atelier parses the CLI's text output (': error ' diagnostics, step lines, the zinc plugins table): read a --json form once the CLI translates those lines; (3) examples hello/text/interface could take their words from zinc:i18n so the thumbnails match the language.
