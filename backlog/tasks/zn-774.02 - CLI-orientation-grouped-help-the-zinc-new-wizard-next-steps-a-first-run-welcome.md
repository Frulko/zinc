## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done (parallel worktree, 2026-10-22).
- zinc and zinc help: Start here (new, run, dev, check, doctor, explain), Build and ship (build, pack, export, publish), More (one line: zinc help --all lists every command). zinc help <cmd>: the usage, then Examples (two for new, run, dev, check, doctor, explain, build), then the detail. Every command summary moved to i18n/<lang>/cli.json (cli.cmd.<name>); the long details stay English. Did-you-mean ranks by edit distance (zinc hlep -> help); zinc version works.
- zinc new with no argument at a terminal (stdin and stdout TTYs, CI unset): a question with the arrow keys and Enter (raw termios, redraw cut to the terminal width; Esc or Ctrl+C cancels), numbered rows when TERM=dumb, then the folder name (my-<template> by default). Without a terminal: the usage, exit 2, nothing written. zinc new --list: the templates by what they make (Games, Apps, 3D, Tools, Boards, More), one short line each; the index block lists only the names that are not local templates. zinc new <template> <dir> unchanged.
- After zinc new: the next steps (cd, zinc dev, the file to change, the lessons https://frulko.github.io/zinc/docs/learn/ first, the guide, zinc tour). The 13 template READMEs start with the same block (the plugin one without zinc tour). The docs base is one constant (kDocs) in src/cli_core.cpp.
- The first bare zinc at a terminal greets, offers the five languages (1 to 5, Enter keeps the guess), saves lang and "welcomed" in $ZINC_HOME/config.json (unknown keys kept), and shows three steps; never under CI or without a TTY.
- install.sh and install.ps1 end with zinc --next-steps (a hidden flag: the three steps, in the user's language); the Homebrew caveats carry the same English lines (first_run checks they match).
Decisions: "welcomed" is a key of config.json (beside lang), not a separate file; --next-steps is not listed in zinc help (only the installers call it); zinc tour is printed before ZN-774.05 adds it (the same parent ships it); the plugin template's README has no zinc tour line.
Tests: tests/run --only first_run PASS (bare zinc, grouped help, help <cmd> examples, hlep, version, zinc new without a TTY and under CI, --list grouped, next steps, READMEs, the wizard through a pty with arrows and with TERM=dumb numbers, the welcome in French and its saved config, no welcome under CI or without a TTY, installers and Homebrew caveats); templates, templates_index, plugin_starter, i18n, cli_core PASS. A first first_run run failed only on the server and service templates (port 3000 held by another tree's test at that moment); the rerun alone passed.
Not proven: install.sh, install.ps1 and the Homebrew install end to end (only their text is checked); the wizard on Windows (numbered fallback, not built here).
