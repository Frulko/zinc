## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
From backlog/later.md, promoted by the review of 2026-10-25 (docs/reports/backlog-review-2026-10-25.md). The lines it carries:

- ZN-774.12: `zinc:ui` has no `.d.ts` (`lib/ui.d.ts` is a placeholder), so editors show beginners no `PointerEvent`, `KeyEvent` or event attributes: generate it from `lib/std/ui.ts`.
- ZN-774.12: `app.window` in `zinc.json` should not need `app.id`: a first project wants a window size, not a bundle id.
- ZN-774.12: a `Button` with no `bg-*` class is a dark box on a light page: let its default follow the page, or say so in `docs/ui-kit.md`.
- ZN-774.18: zinc:ui/kit has no Input or Textarea; kit apps style host fields by hand (shadcn's Input: h-9, rounded-md, border, px-3, text-sm).

Test: tests/t0/ui_dts.sh (stale check + tsc -p on a zinc tsconfig project: a correct program passes, e.nope on onPointerDown is an error).
- AC2: project.cpp no longer requires app.id when "app" is present; a wrong id is still refused; bundling keeps its own checks (--bundle, --dmg) and the manifests default to dev.zinc.<name>. Regression in tests/unit/project_test.cpp (project_assets).
- AC3: the host <Button> already draws nothing (D163), so with no bg-* it shows the page (checked on a headless shot); docs/ui-kit.md now says so, and that the kit's default variant is filled with the theme primary (near black on LIGHT, as shadcn's) while outline/ghost follow the page.
- AC4: lib/std/kit/input.tsx: Input (h-9 py-1) and Textarea (min-h-16 py-2, rows 3) with rounded-md, border-<input>, bg-transparent, px-3, text-sm, placeholder:text-<mutedForeground>, focus:border-<mutedForeground>, opacity-50 when disabled; exported from zinc:ui/kit, docs/ui-kit.md rows, tests/t0/kit_input.sh (36 px input, taller textarea, typing reaches onInput, a disabled field takes no focus). Engine fix found by the test: ui.focusNode gave the focus to a disabled node (DOM focus() refuses); it now refuses.
- Research: shadcn new-york-v4 input.tsx / textarea.tsx (https://raw.githubusercontent.com/shadcn-ui/ui/main/apps/v4/registry/new-york-v4/ui/input.tsx, .../textarea.tsx): h-9 rounded-md border-input bg-transparent px-3 py-1 shadow-xs md:text-sm, placeholder:text-muted-foreground, focus-visible:border-ring ring-3, disabled:opacity-50; Textarea min-h-16 py-2 field-sizing-content. Tauri requires identifier only to build (https://tauri.app/reference/config/), Electron/Expo ask for an app id only when packaging: same choice here. shadcn's/Nuxt UI's default button is a solid primary that flips with the theme; RN's Button is platform blue.
