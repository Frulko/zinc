## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Second half of ZN-364 (split 2026-10-08). With useNativeDriver: true, timing/spring/decay of a value bound to transform (translate, scale, rotate) or opacity run in the engine's frame loop (the property slots of R5.3 / ZN-191, unparked for this), not in the program; a value bound to a layout prop with useNativeDriver: true fails with React Native's error text.

Session 2026-11-09 (worktree agent). Research (sonnet sub-agent): RN native driver sends the node graph once (value, interpolation, props, style, transform, arithmetic nodes) and native plays it on CADisplayLink/Choreographer, so it keeps moving while JS is blocked; the old timing driver sent a precomputed frames array (https://reactnative.dev/blog/2017/02/14/using-native-driver-for-animated); allow list NativeAnimatedAllowlist.js (0.76) and the error texts of NativeAnimatedHelper.js validateStyles/validateTransform (https://raw.githubusercontent.com/facebook/react-native/v0.74.0/packages/react-native/Libraries/Animated/NativeAnimatedHelper.js); native spring is the closed-form oscillator at elapsed t (ReactCommon/react/renderer/animated/drivers/SpringAnimationDriver.cpp); JS value is stale during a native animation and synced at stop/finish. Reanimated worklets (https://docs.swmansion.com/react-native-reanimated/docs/2.x/fundamentals/shared-values) rejected by D182 (no worklets). Flutter OpacityLayer/TransformLayer update the layer property without repainting children (https://medium.com/@pomis172/understanding-composited-layers-to-improve-the-performance-of-flutter-apps-7b91079b4dd1). Core Animation: model vs presentation layer, render server plays the animation (https://www.wwdcnotes.com/notes/wwdc14/419).
Design (decisions for the coordinator): (a) the native driver samples the animation once when it starts, as RN's frames array, generalised to spring and decay (step 1000/60 ms; timing a whole number of steps ending at its duration): a series of values per binding, replayed linearly by ui.ts and by the compositor (include/zn/ease.h series_at), so any easing function, interpolation chain and offset work without code on the compositor; (b) bindings are explicit, A.attach(node, key, value) (the strict style types cannot hold an Animated node as RN's Animated.View style does); (c) RN's error text for a key outside NativeAnimatedAllowlist, thrown from start(); colours and diffClamp fall back to the program; (d) during a native animation value.get() is computed when read (exact, same as the program-driven path), the signal and listeners hear the end only (RN's stale JS value); an engine-clock alarm (ui.alarm) ends it without a stepper (a stepper keeps every frame painted); (e) compositor props now 0 rotate, 1 translateX, 2 translateY, 3 scaleX, 4 scaleY, 5 opacity, several per layer, matrix T R S in paint's order; a move-only layer is shifted with box()'s own arithmetic so slot frames equal re-recorded frames bit for bit (T0 animated_native: 60 frames identical on/off, also at ZINC_SCALE=2); (f) only series (native driver) and the existing rotate go to the compositor: animate() translate/opacity and the transitions (#4) are not moved yet, to keep the existing goldens.
Explicit state: ui.ts Anim has one lifecycle (ANIM_RUN -> ANIM_DONE | ANIM_STOPPED, animEnd), monotonic uids for series (stopSeries, animState), done(finished) called when stepAnims drops it, which also fixes the audit's 'a replaced animate() never resolves' (implicit-state-machines.md ui.ts tweens); node handles get a monotonic serial (ui.nodeSerial) so an Animated binding to a released, recycled node writes nothing; animated.ts Animation has one lifecycle (A_IDLE -> A_SCRIPT | A_NATIVE -> A_ENDED, transition()).
Proofs: #1 tests/t1/busy_native.sh (real clock, ZINC_RENDER_THREAD=1 headless: longest gap 28 ms and 54 compositor ticks while the program busy-waits 1 s; 1000 ms frozen from the program); ZINC_PROFILE=json now has screen.gap_max and screen.ticks (presents of any thread). #2 and the lifecycles: tests/t0/animated_native.sh (interpreter, QuickJS; AOT checked by hand: same output). #3 tests/t1/animated.sh runs tests/golden/animated again with ANIMATED_NATIVE=1 (useNativeDriver on every animation): same output (checked by hand on interpreter and QuickJS, not as the T1).
Left: #4 (transitions of opacity/transform through the compositor: mark trans anims comp in trChange, redeclare on retarget, showComp for layered; check ui_transition goldens) and #5's long-list scroll half (D182 step 7, compositor scroll).
