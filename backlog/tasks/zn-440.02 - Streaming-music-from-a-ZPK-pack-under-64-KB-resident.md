## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-11-09. API: loadMusic(name): Music (zinc:audio), music.loop (loadMusic and openMusic), music.memory. Native: zn_asset_view/zn_asset_unview (src/host/sys_host.cpp): a mounted pack's entry stored as none, in place from the mapping (assets::view pins the pack: unmount refuses while a music reads it), else a file of the assets directory mmapped; the plugin decodes it with ma_decoder_init_memory (f32, the file's own rate and channels) as the data source of an ma_sound, so the decode runs on the mixer's thread as the mix pulls frames (no thread, no ring); a loop is miniaudio's data-source loop (seek inside the read that reached the end), seamless across the resampler. Memory counter: a counting allocator for the decoder (and for the engine, its delta around the sound's init = the node), plus stb_vorbis's setup_memory_required (it mallocs on its own; probed once). Music handles now carry a generation (gen << 2 | slot); musicOpen no longer leaks its source, mutex and condition on failure (audit item). The asset build and writePack store sound files as none (zpk::readInPlace, pack cache key bumped). Engine gap fixed: QuickJS had no __host_assetsPackAdd/PackWrite (writePack threw); added to isSysTailRow.
Decision: the codec is the file the user packs (the importer of ZN-440.01 does not exist yet; QOA is not vendored); the 64 KB bound holds for WAV (IMA ADPCM or PCM), FLAC and MP3, not Ogg Vorbis. Measured music.memory on a 4 s stereo 44.1 kHz track: IMA ADPCM WAV 4672 B, PCM WAV 4672 B, FLAC 17024 B, MP3 128 kbit/s 36656 B, Ogg Vorbis (Kenney jingle, libvorbis) 230472 B (stb_vorbis setup 176 to 194 KB on the six repo oggs measured).
Proof: tests/t0/audio_stream_pack.sh (new): a 4 s IMA ADPCM WAV made by the test (left 390 Hz sine, right opposite) written with writePack, mounted, loadMusic, loop, 10 s of mix: 'hash 584403488 position 2.029', no step above 0.04 nor a silent run at the two loop points, right = -left, memory 4672 under 64 KB, unmount refused while playing and accepted once closed, a missing asset's error; same lines on the interpreter, QuickJS and the AOT program. tests/run --only audio_stream_pack, audio_fade, assets, assets_report, zpk, webenv_audio_silent, console_audio: PASS.
Research (sonnet sub-agent): QOA frames (5120 samples, independent LMS state per frame: exact seeks and loops, ~270 B state) https://raw.githubusercontent.com/phoboslab/qoa/master/qoa.h ; stb_vorbis alloc buffer and setup memory ~150 KB+ https://github.com/nothings/stb/blob/master/stb_vorbis.c ; miniaudio custom data sources and decoders https://miniaud.io/docs/manual/index.html ; Godot's Ogg loop with a short crossfade https://remotebranch.eu/Stowage/godot/src/commit/002028ea408927720496606d36701c44147e6ac6/modules/vorbis/audio_stream_ogg_vorbis.cpp
Proposed tests: tests/t1/audio_music.sh (openMusic now loops and reports memory: the existing session, ~10 s, <200 MB); loadMusic of a 10-minute IMA ADPCM track in a pack, RSS before and after 60 s of mix (window-free, ~1 min, <200 MB) to show the mapped pages stay page cache; a short run on the Pi 3B+ of the same T0 (decode CPU per codec on the mixer thread).
