## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Engine packs are TUF targets engines/<engine>/<version>/<host>.tar.xz with custom {zn_engine_abi, napi, upstream}; first use of --engine downloads the newest pack this zinc speaks into ~/.zinc/engines, checks hash and signature, dlopens it with an ABI check. zinc engine list|install|update|remove, a doctor line, ZINC_ENGINE_<NAME> for own builds, the daily check of selfupdate names a newer pack; export/pack/fuse copy the pack and sign-macos adds allow-jit.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-10-21. `src/tc/engines.{h,cpp}` (zn_tc), `tools/engine-pack`, `zinc engine`, `tests/t0/engine_pack.sh`.

Layout (one each, decided here):
- Index target: `engines/<name>/<version>/<host>.tar.xz` (host as `zn::tc::hostName()`: aarch64-macos), top-level role only (native code: never a delegated publisher's), custom `{kind: engine|module, library, zn_engine_abi, napi, upstream}`. Generic: a `module` pack (ZN-773.06's `wasm`) names its own library; `engines::locate/install(name, abi)` take the ABI to check.
- Archive: `<library>` at the top with rpath `@loader_path/lib`, `lib/` (its @rpath dylibs and the .dat beside them: icudtl.dat), `licenses/`; every Mach-O signed ad hoc. Version = the upstream's by default (`--version` otherwise).
- Installed: `~/.zinc/engines/<name>/<version>/` + `pack.json` (the signed custom, the version, the archive's SHA-256). `available` (daily check) and `.checked` beside.
- The V8 SDK of tools/v8-pack moves to `~/.zinc/sdk/v8/<version>/{include,lib}` (CMake default `ZN_V8_DIR` follows); it is never a pack.
- Lookup of a module (run): $ZINC_ENGINE_<NAME>, beside zinc, `<app>/Contents/Resources/engines/<name>/`, the newest installed pack with this ABI, else download now. Export prefers an installed pack over the module beside zinc (a source build's v8 links the build machine's SDK by absolute rpath).
- Exported app (`"engine": "jsc"|"v8"`, macOS): Contents/MacOS/zinc (the executable, signed with allow-jit and disable-library-validation), libzn_window/webgl beside it, Contents/Resources/app/{app.js, app.js.map, engine, capabilities.json} (bundled at export: no esbuild on the user's machine), Contents/Resources/engines/<name>/ (the pack: data and code, so in Resources; codesign refuses non-code in Contents/MacOS). zinc sees Resources/app/engine at launch and runs it. `codesign --verify --deep --strict` passes.

Proof: `tests/run --only engine_pack` PASS (also jsc, v8). The real V8 pack by hand: tools/engine-pack v8 -> 13.9 MB, 11 libraries; a zinc with no v8 beside it, file:// index: "v8 15.6.75.19: downloading 13.9 MB ... installed ... 1.7 s", Intl works (`1.234.567,891`); its export (96 MB .app) runs with an empty ZINC_HOME and no index.

Publishing (the owner's step; nothing published): once `tools/index-repo keys keys.json` exists (docs/plugins.md),
  tools/v8-pack && tools/build zinc
  tools/index-repo entries . e 1
  tools/engine-pack v8 --entries e/entries.json
  tools/index-repo build idx keys.json e/entries.json   # later publications: add index/root.json (the root zinc ships) as last argument
then commit idx/root.json as index/root.json (the first time), upload idx/ to https://zinc-engine.github.io/zinc/index (ZINC_INDEX_URL's default) (no trusted root is in the repository yet, so `zinc run --engine v8` without a source-built module says it cannot read the index).
