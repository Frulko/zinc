## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- Need → provider → gap: `zinc:gfx` already owns paths, polygons, rounded boxes, fonts and drawing; `zinc:ui` owns Canvas clipping, local pointer coordinates, focus, keyboard, reduced motion and lifetime; the kit owns Quiet roles and neutral hooks. Existing Metric/CallStats and hero histories are specialized consumers, not reusable axis/layout providers. Added a pure `chart-model.ts` and one `charts.tsx` family, using existing Animated.Value/spring for gauge motion. No renderer, layout engine, dependency or native build.
- Primary reference pinned to CUI `f70a1d3d095cafd67814b23bdd82c2dfba28efe0`: [core chart contract](https://github.com/yappologistic/CUI/blob/f70a1d3d095cafd67814b23bdd82c2dfba28efe0/docs/components.md#charts), [more charts](https://github.com/yappologistic/CUI/blob/f70a1d3d095cafd67814b23bdd82c2dfba28efe0/docs/components-more.md#more-charts), [chart source](https://github.com/yappologistic/CUI/blob/f70a1d3d095cafd67814b23bdd82c2dfba28efe0/src/cui_charts.c), [visualization source](https://github.com/yappologistic/CUI/blob/f70a1d3d095cafd67814b23bdd82c2dfba28efe0/src/cui_viz.c). Reference input semantics and range labels were checked against [WAI APG](https://www.w3.org/WAI/ARIA/apg/patterns/slider/); charts use inspection buttons/status, not a misleading editable slider role. Reference copies remain in `.logs/charts-reference/`; no CUI source was vendored.
- All fifteen types are included: line/area/grouped or signed-stacked bars, donut, sparkline, gauge/radial gauge, heatmap, squarified treemap, radar, funnel, bounded cyclic Sankey, largest-remainder waffle, scatter/bubble and zoom/pan candlesticks. Models and hit regions share one geometry. Empty/non-finite data, labels/formatters, range/grid/legend options, original point indices and callbacks are retained. Price view follows appended data only at the right edge, aggregates OHLCV to at most 880 columns and reads only the visible range on viewport changes.
- Keyboard inspection is native focus with Home/End/arrows/Shift-ten, Enter/Space and Escape. Price Home/End use original global candle indices even while zoomed. Pointer uses exact painted marks, rejects donut holes and follows actual focus/drag/cancel cleanup. Floating hover values and a live accessible status complement crosshairs. Gauge spring belongs to the component, stops on unmount and snaps on live reduced motion; there is no permanent frame loop. Canvas draw buffers are reused, and a per-view colour cache is bounded by the current model/theme rather than accumulating colours across updates.
- Input work is bounded with explicit RangeErrors for oversized series/items/graphs; the documented caps are UI contracts, not silent truncation or throughput claims. Large data arrays should retain identity between updates and be replaced when editing their contents. Waffle dimensions clamp to 1–50. Native OS assistive technology, physical touch and quiet-machine performance remain proposed checks.
- Initial source896b/Charts-only unchanged gate PASS: minified JS235962/240811/277503 B (unused4849<8704;4076/component), AOT5325320/5391376/5926640 B (unused66056<139264;59473/component). These are source-specific size numbers, not the final combined Code/Charts measurement. No UI option removed or budget raised. Final combined gate follows after rebase to Code integration4782de13f.
