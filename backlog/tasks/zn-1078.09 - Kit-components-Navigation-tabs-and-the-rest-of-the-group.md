## Implementation Notes

Navigation implemented in `lib/std/kit/navigation.tsx`, with the existing basic `Tabs` API in `tabs.tsx`. Added grouped/collapsible and compact sidebars, ancestor overflow, zero-based pagination, step statuses and linear/vertical layouts, scroll-following contents with nested entries, named dock actions with badges/running marks, and compact tab bars. All navigation controls take keyboard input and show the engine's focus-visible ring. Rich tab/sidebar/contents markers use the existing springs and reduced-motion path. The original Tabs string-array/accessor/onSelect contract and platform looks/haptics are retained; icons, tooltip providers and animated markers stay in NavigationTabs rather than basic Tabs.

Reused the existing Nuxt page-number algorithm by moving its pure function to `lib/std/pagination.ts`; Nuxt's public `pageItems` re-export remains compatible. Kept DocumentTabs and DockLayout as the existing app-chrome capabilities. Icons use Zinc's existing per-name provider and gallery manifest; no dependencies, inline SVGs, registration effects or engine edits. The reference Dock's magnification is deliberately omitted because `docs/design.md` forbids decorative hover growth; running/badge/separator/tooltip/keyboard capabilities remain.

Research: CUI primary component docs https://github.com/yappologistic/CUI/blob/master/docs/components.md (tabs, sidebar, breadcrumb, pagination, stepper) and https://github.com/yappologistic/CUI/blob/master/docs/components-more.md (contents rail, dock, tab bar). Adopted horizontal tab reveal, grouped navigation, first/last pagination gaps, nested anchor navigation and labelled launcher actions. Research was supplied by the coordinator before implementation; no second research agent was launched.

Proof: `zinc check examples/ui/kit-gallery` passes. `tests/run --only kit_navigation` passes on the coordinator's clean smoke binary, with Solid and React fixtures on interpreter and QuickJS: disabled skips/activation, tab wrap/Home and horizontal reveal, collapsible groups, hidden breadcrumb menu activation, pagination boundaries, linear step control, contents follow including a last section too short to reach the viewport top, dock actions and compact tab-bar keys. Built and ran the same Solid interaction program as an AOT executable (`navigation: ok`). All commands used the shared `tools/work-run` timeout/lock; headless, no persistent process.

Light and dark gallery pictures drawn by Zinc QuickJS were inspected and saved as `docs/img/kit-navigation.png` and `kit-navigation-dark.png`; each of the eight controls is documented in `docs/ui-kit.md`, including model-neutral contents handle accessors.
