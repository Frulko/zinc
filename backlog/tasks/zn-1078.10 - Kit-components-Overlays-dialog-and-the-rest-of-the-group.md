- Primary research: [CUI components](https://github.com/yappologistic/CUI/blob/master/docs/components.md), [additional components](https://github.com/yappologistic/CUI/blob/master/docs/components-more.md), [WAI modal dialogs](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) and [tooltips](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/). Relevant options: 440 px dialogs/persistent dismissal, scrolling sheets, hover dwell/grace, confirmation focus, persistent/action toasts, interactive tour targets. Modal surfaces alone declare aria-modal and block the page; existing menu focus behavior is preserved.
- Parent rerenders retain uncontrolled open state through the shared host.componentRef helper. Owned focus subscriptions use the shared disposer (d78054826, focused replacement snapshot 8fc1bb2d1). Tooltip and hover-card deadlines retain elapsed UI time across React rerenders; cleanup cancels only that render's timers/subscriptions. Tooltips append/remove their own described-by id while preserving the caller's description, never take focus, and reject stale handles.
- Toast Running/Paused/Closed states account for pointer/focus overlap, new arrivals while paused, persistence, action/dismiss controls and horizontal drag. Tour spotlights swallow outside input while leaving an optional target interactive; target generation changes remove the anchor and center the step. Watchers are removed on replacement/unmount.
- The original gallery works with GALLERY=overlays and OVERLAY=hint/popover/hover/confirm/toast/dialog/sheet/tour; existing Selection exports/gallery/docs are preserved. Eleven actual Zinc pictures are documented in docs/ui-kit.md, including dark hover/dialog. Visual inspection found and fixed overflowing dialog/toast rows with the existing shrinking layout classes.
