# bounce

A looping video bouncing around the screen like the DVD logo; the frame changes colour on every bounce and corner
hits are counted. The video is decoded straight at the size it is drawn (`new Player(w, h)`), so drawing it is a row
copy.

```sh
zinc run examples/video/bounce                                  # media/fractal.mp4
zinc run examples/video/bounce -- my.mp4 --size 400 --speed 300
zinc build examples/video/bounce --target rpi1                  # fbdev display on the Pi
```

Keys: Space pause, Up/Down speed, Esc quit. `media/fractal.mp4` (192x108, 4 s) is generated by `../make-media.sh`.
