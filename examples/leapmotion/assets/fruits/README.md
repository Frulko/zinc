# Fruit textures

These are open-licensed alternatives for the fruit-slicing demo, not original Halfbrick Fruit Ninja assets.
All seven images are unmodified 1024×1024 source files under CC0-1.0. The game uses their colour maps; no normal/roughness
maps, model archives or third-party binaries are needed. Sources and SHA-256 hashes are pinned in `SOURCES.json`.

| Files | Author and source |
|---|---|
| `apple-skin.jpg` | TextureCan, [Food 0006](https://www.texturecan.com/details/185/) |
| `orange-skin.jpg` | TextureCan, [Food 0022](https://www.texturecan.com/details/451/) |
| `watermelon-skin.jpg` | TextureCan, [Food 0001](https://www.texturecan.com/details/111/) |
| `orange-cut.jpg` | TextureCan, [Food 0023](https://www.texturecan.com/details/452/) |
| `apple-cut.png`, `kiwi-cut.png` | qubodup, [Fruit Cut Open for UV Maps](https://opengameart.org/content/fruit-cut-open-for-uv-maps), derived from the public-domain photographs linked there |
| `watermelon-atlas.png` | nevak, [A watermelon](https://opengameart.org/content/a-watermelon), `Melon/dif.png` |

[TextureCan's terms](https://www.texturecan.com/terms/) explicitly permit redistribution with projects. The OpenGameArt
author pages identify their images as CC0. The licence text is included in `LICENSE.txt`.

The renderer maps the cut-face photographs onto circular caps. Watermelon uses the lower-right region of its atlas through
mesh UVs; image bytes are unchanged. Kiwi skin and bomb materials are generated by the demo. No downloads happen at runtime.
