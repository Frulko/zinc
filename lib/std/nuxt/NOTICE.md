# Notices for zinc:ui/nuxt

The kit in this folder follows the look of Nuxt UI 4 (nuxt/ui 4.11.3, commit 9c4e33b7): its design tokens, the classes of its component themes and its sizes
are re-expressed for zinc:ui (no Vue code is copied). Research: docs/reports/nuxt-ui-research.md; decision D38 in docs/reports/zinc-next-decisions.md.
