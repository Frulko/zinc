# Frozen pinball conformance fixture

These sources are the pinball simulation used by the frozen `tests/conformance/pinball_physics.*.out` outputs, preserved from develop at the start of the 2026-10-25 physics changes. They exercise language and numeric profiles, not current game balance. Do not tune or regenerate them.

The live reusable simulation is `examples/pinball-kit`; `tests/demo/pinball_physics.sh` tests its physical invariants and the Jolt adapter.
