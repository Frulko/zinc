Carnet is a block editor that keeps your pages as Markdown files in a folder. This one runs Carnet's own code on Zinc: no browser, one native program.

## Try it

- [ ] Type `/` to open the menu of blocks
- [ ] Start a line with `# `, `- `, `[] ` or `> ` to change its type
- [ ] Drag a block by the grip on its left
- [x] Open a second window: each window is another person

> [!note] Every page is a `.md` file in the `vault/` folder next to the app. Open it in any editor or in Obsidian.

## Keyboard

1. Enter splits a block, Shift+Enter starts a new line inside it
2. Backspace at the start of a block turns it back into text, then joins it to the one above
3. Tab and Shift+Tab nest a block
4. Cmd+Shift+↑ and ↓ move a block, Cmd+D duplicates it
