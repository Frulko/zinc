# Glossary of the translations (D159)

Every catalog of `i18n/<lang>/` uses these words, so the CLI, Atelier, the tours and the docs say the same thing.

Register: **vous** in French, **tú** in Spanish, **tu** in Italian, **du** in German. Short sentences, plain words: the readers
include beginners and children.

Never translated: Zinc, Zinc Atelier (Atelier), command names (`zinc run`), flags (`--lang`), file names (`zinc.json`),
module names (`zinc:gfx`), error codes (`Z0103`), anything between backticks, Fast Refresh, TypeScript, JavaScript.
