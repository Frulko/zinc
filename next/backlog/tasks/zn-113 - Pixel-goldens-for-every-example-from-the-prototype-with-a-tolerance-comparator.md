## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The requirement is pixel parity with the prototype, but only 3 example goldens exist. Build tools/proto-capture: render each example (entry, frame list, window size, scripted input from the example's own test script when it has one) with the prototype's native macOS build (`node compiler/bin/zinc.mjs run <ex> --capture ...`, deterministic mode) and store PNGs plus a manifest in tests/golden/examples/proto/. Add tools/pngdiff modes: exact, per-channel tolerance with a count of differing pixels above it, and a perceptual summary; a report image of differences. Define the tolerance policy (exact for text-free UI, small tolerance where a library replaces the prototype's renderer: ThorVG, HarfBuzz).
<!-- SECTION:DESCRIPTION:END -->
