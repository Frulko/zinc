## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ZN-563 gave zinc:3d a GPU renderer with the kinds the native interface carries: unlit and Lambert (per-vertex, clamped), smooth or flat, textured, vertex colours. three's MeshPhongMaterial and MeshStandardMaterial still draw as Lambert. Add specular (shininess, specular colour) and roughness/metalness to the interface (render3d.spec.ts draw or a material call), per-pixel Phong and a Standard approximation on the GPU where the tier allows, and the closest software shading (per-vertex specular) so that the software renderer stays the oracle within SSIM.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done: render3d.spec.ts specular(color, shininess) (begin() resets it to none); Engine::shade adds Blinn-Phong with three.js's BRDF_BlinnPhong factor (spec x lc x n.l x (s/2+1)/4 x (n.h)^s, eye from the view matrix) per vertex in software; the GPU has a SPEC program variant (world normal varying, per pixel, flat uses the derivative normal). zinc:3d Material.specular/shininess (sent on change). three: Material.specular (0x111111), Phong -> specular/shininess; Standard/Physical -> exponent clamp(2/r^4-2, 1, 1000), F0 = mix(0.04, colour, metalness), metals lose their diffuse, no highlight when its peak is below 4/255 (roughness ~1, the GLTF loader's default).
Tests: tests/data/three_specular (Phong + Standard + metal spheres): software frame = new golden tests/golden/examples/three-specular-3.png (interpreter identical), GPU SSIM 0.9987 against it (tests/t1/three_gpu.sh, passes). AC2: three/cubes software frame 30 is the same as before the change (5 px max diff 1 against the golden, the known three_3d machine diff); 3d/cubes, 3d/model, three/gltf-viewer unchanged too (cube faces barely catch per-vertex highlights; on the GPU three/cubes keeps SSIM 0.9999). plugin_manifest passes; scene3d.ts/three.ts conformance unchanged.
