## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
After ZN-592.06 a compiled console program with a timer links libSystem and libc++ only and starts in 7.0 ms against 4.9 for an empty program (Intel Mac): the rest is mostly dyld resolving ~240 libSystem imports (~1.2 ms) that the host's row dispatch (src/host/gfx_host.cpp and sys_host.cpp: one switch over every row: sockets, HTTP, TLS, MQTT, processes, files...) keeps alive through -dead_strip. Let the AOT emitter call the rows a program uses directly (as it already does for the hot gfx rows, ZN-397) or split the dispatch per family so that the linker drops the families a program never calls; measure the imports and the launch.
