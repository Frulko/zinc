## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`zinc pack [dir] -o app.zapp`: the ZBC, the baked resources, the assets and the manifest (zinc.json subset, engine version, a signature slot) in one deterministic archive; `zinc run app.zapp` runs it; double-click on macOS/Linux opens it with zinc.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 two packs of the same project are byte-identical
- [ ] #2 `zinc run app.zapp` gives the same output and frame as `zinc run dir`
- [ ] #3 an archive made for a newer engine, or a corrupted one, is refused with a clear message
<!-- AC:END -->
