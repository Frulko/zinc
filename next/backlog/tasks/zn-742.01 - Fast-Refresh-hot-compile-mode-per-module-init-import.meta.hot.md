## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-10-16 (worktree agent). Built step 1 of docs/reports/zinc-next-fast-refresh.md §7 A; what and where in §9 of that report.

- ZINC_HOT=1 turns hot mode on (loadChecked, main.cpp; in the build-cache signature). Nothing sets it yet: zinc dev sets it on its child in ZN-742.02, with the swap.
- import.meta.hot: parser marker __meta_hot, then hotMeta (frontend/modules.cpp) per file. Outside hot mode, statements that only run with it become empty nodes; other uses are null. In hot mode, if-tests become true and other uses become __zinc_hot('<path>'), bound by an implicit import of zinc:hot's hotModule.
- zinc:hot = lib/std/hot.ts, loaded first in hot mode only: HotModule (accept, dispose, on) and beforeUpdate/afterUpdate. lib/zinc.d.ts types ImportMeta.hot.
- Lowering in hot mode: one @init:<path> function per module; main runs the prelude, the inits in order, then __runLoop. Every top-level variable is a global. Inits and zinc:hot functions are Function::entry (never inlined or dropped).
- Stable keys on Function, Class and Global (ir.h Module::hot); ZN_DUMP_HOT_KEYS=<file> dumps them in ZBC index order.

Deviations from the design, with reasons:
1. __runLoop() stays in the last module's statements, so the checker still checks it; Ast::runLoop marks it and the lowering moves it into main.
2. zinc:hot is bound by an implicit import added per module, not a prelude. Its hooks stay real module functions with keys.
3. Every top-level variable is a global in hot mode, so module state outlives its init and has a key.
4. Lambda keys add ' in <generic instance>' and '.n' for desugared lambdas that share an offset; record keys take their declaration's file. Without these, keys collided on the desktop-app.

Proof:
- tests/run --only hot_off: PASS, 6 s.
- 48 programs compile to byte-identical non-hot ZBC before and after: tests/conformance/*.ts, hero, breakout, nuxt-ui, lang, modules-showcase, rn-showcase, desktop-app.
- The hot desktop-app renders the same frame 10 as the non-hot one.
- PASS: modules, checker, parser, plugin_manifest, ir, zbc, rc, rc_refcast, rc_lend, rc_borrow, virtual_default, std_surface, tdz, zbc_cache, run_cache, affected_paths.
- tools/diff-matrix on conf:async, errors, modules, features and generic_static: aot=ok. interp=DIFF there also happens with main's binary, so it is not from this change.
- lexer fails on its ui.tsx golden with main's binary too: className migration, not touched here.
