## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
(Left by the pinball table editor, ZN-649.04, see its decision record.) File fields (sounds, textures, models, panel images) are typed paths. They become a chooser of the folder's files with a thumbnail or a length, an import that copies a file into the folder, and a refresh when a file changes on disk (`forgetImages()`). The largest gap for someone who does not code.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-10-11 (parallel agent, worktree).

What changed
- Format: a file field says what kind of file it names (schema.ts: Kind.Asset carries 'image', 'sound' or 'model' in Field.to; table-schema.ts FILE_KINDS and fileKind() give the extensions of each). The reference prints 'image file', 'sound file', 'model file'. No file of a table changes.
- Editor (src/files.ts): the files of the table's folder are read (three folders deep, table.json and dot files left out); every file field of the form is a list of the files of its kind (widgets.tsx Picker: the Chooser with a picture and a note per line, and a box to type in: Enter takes the first match), with a thumbnail and the size for an image, the length and a play button for a sound, the triangle count for a model, 'not in the folder' for a file the table names and the folder lacks. 'Import...' in each list, the + of the Files group and Cmd+I ask the system for a file and copy it into the folder (sounds/ for a sound, art/ for an image or a model); a file dropped on the window is imported the same way; a file of the same name is replaced only after a question. Refresh (Cmd+R, the button of the Files group, and after every import) calls forgetImages(), forgets the decoded sounds and the built scene, and reads the folder again. The outline has a Files group: the files, the ones nothing names marked 'unused' (and counted on the group's line); a click on a file, or its name typed in Go to (Cmd+G), says what names it and selects that thing.
- Which fields name files is read from the schema (files.ts named()): a file field added to the format is offered and counted without editor code.

Proof (tests/t1/pinball3d_editor_files.sh, new; session tests/golden/pinball3d-editor/files.input, file golden files.json)
- AC1: the session picks art/paint.png for the board's look, sounds/tick.wav for a new sound (heard: 'preview: file sounds/tick.wav'), art/pyramid.obj for a model, and imports clink.wav through the scripted dialog ('imported sounds/clink.wav', same bytes in the folder); the saved table equals files.json and the game's loader accepts it. Output: 'pinball3d_editor_files: ok'.
- AC2: another paint.png dropped on the window replaces the folder's ('imported art/paint.png'); the top view and the 3D pane at frame 76 differ from frame 26 and equal, pixel for pixel in that part of the window, the same frame of a run on a folder that had the second painting from the start.
- 'files: 5 in the folder. 1 unused: art/spare.png.' and 'art/pyramid.obj (4 triangles): named by models[1].mesh.' are in the session's log.
- PASS pinball3d_format, pinball3d_editor (its two form goldens form-8.png and form-fr-8.png rewritten: the fixture's file field is now the list with its play button and note), pinball3d_editor_table, pinball3d_editor_files.

Decisions
- Imported files go to art/ and sounds/ as Tidal Lock's do, so two tables made with the editor have the same folder shape.
- An import over an existing name asks first (it would silently destroy a file of the table otherwise).
- Refresh is a command, not a watcher: zinc:fs watch polls every 100 ms and keeps the program alive; a button and a key are enough and are testable.

Not verified / limits
- A file changed by ANOTHER program during a run and then Cmd+R: no test can change a file at a known frame (headless runs are not paced); the drop exercises the same reading again. A real drag from the Finder and the real file dialog were not exercised (no person at the window).
- The length of a sound is 0 in a deterministic run (zinc:audio is a stand-in there), so the note of a sound is only shown in a real run.
- The system script counts passes of the event loop (1.5 to 2 a frame here): the test's drop sits in the middle of a 57-frame pause of the session.
- affected.json to add: pinball3d_editor_files for examples/pinball3d-editor/** and examples/pinball3d/src/**.
