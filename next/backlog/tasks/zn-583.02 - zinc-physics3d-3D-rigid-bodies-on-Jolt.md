## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The 3D half of ZN-583, needed first by the 3D pinball (ZN-649). A plugin `plugins/physics3d` on Jolt Physics (MIT), vendored inside the plugin with its licence, pinned version and checksum: a world with a fixed step and deterministic stepping; static, kinematic and dynamic bodies; shapes (sphere, box, capsule, cylinder, convex hull, triangle mesh, height field); continuous collision for a small fast body (a pinball); hinge constraint with motor and limits (flippers), slider constraint (plunger); contact added / persisted / removed events with the impulse; sensors; ray and shape casts; per-body friction and restitution; layers and collision filtering. A typed API for compiled Zinc code, the same calls from the interpreter and from QuickJS. No physics in the engine core: a plugin, loaded by programs that import it. (Owner request, 2026-10-10: a pinball all in real 3D instead of fake 3D, with a suited physics engine, a vertical table in the style of Space Cadet, parametrable in its lanes and assets, with a complete editor to make new tables, visual and sound. Owner's answer the same day: complete 3D physics, not 2D in the table plane.)
