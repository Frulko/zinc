## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
What adb gives, through the agent: a remote shell (a command with its exit status, or a terminal), files both ways, apps installed and started on the device with their logs, and ports of the device reached from the workstation (the inspector and the debugger of a running app go through that).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 zinc device <d> shell <command> prints its output and exits with its status; without a command it opens a terminal on the device (PTY, window size followed)
- [ ] #2 push and pull copy a file or a directory tree with the file modes; a name that leaves the destination is refused
- [ ] #3 install takes a .zapp or an export directory; run, stop, apps, logs [-f] and uninstall work on it; the output of a running app is kept in a bounded log
- [ ] #4 forward <local> <remote> makes a port of the device answer on the workstation: /json/list of a running app's inspector is read through it
- [ ] #5 A test on the loopback interface covers the four criteria above
