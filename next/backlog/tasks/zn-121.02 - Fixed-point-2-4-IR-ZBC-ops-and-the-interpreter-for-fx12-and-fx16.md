## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Lower fx values as int32 raw with the exact semantics of runtime/zrt_ext.h Fx<F>: add/sub/neg wrap, mul (int64 a*b)>>F, div ((int64)a<<F)/b and rem with the fixed-point division by zero panic, comparisons as i32, conversions (from double floor(d*ONE+0.5), to double v/ONE, from i32 shl F, to i32), constants, min/max/abs/floor/ceil/round/trunc/sign/sqrt (integer square root), sin/cos from the 4096-entry table (runtime/fx_sin.h, zrt_fx_idx_k), hypot, pow/tan/atan2/exp/log through double, printing and JSON through the double value. New ZBC ops (version bump with a compat fixture), shared in include/zn/ops.h so the interpreter and AOT use the same code.
