## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
(Split of ZN-650.07 proposed by its agent after the storyboard and the sequence editor were done; the editor is `examples/museum-table/editor/`, one operation per feature in `doc.ts` plus a line in `selftest.ts`.) The editor embeds the player's object viewer and panorama view (`src/viewer.ts`, `src/panorama.ts`, `src/orbit.ts`): a click on the model or in the panorama places a point of interest, which is then named, described in each language, given the view the visitor is taken to and, optionally, the sequence it leads to; points are moved and deleted the same way. Also: items turned on the stage with zinc:gfx setTransform, which exists now (rotation was a number in the advanced mode only).
