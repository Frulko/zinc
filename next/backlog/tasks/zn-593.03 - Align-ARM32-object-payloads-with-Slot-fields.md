## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The macOS T2 cross_linux test fails when typed AOT objects are compiled for ARM32: Obj is 12 bytes with 4-byte alignment, but Slot fields require 8-byte alignment. C++ inserts a gap while Obj::fields assumes the payload starts immediately after the header. Align the shared header so the interpreter and typed AOT use the same layout; retain the generated layout assertions.
<!-- SECTION:DESCRIPTION:END -->
