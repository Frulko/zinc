## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
2026-10-11: done without ZN-698: a package is now a pack of the engine (ZN-649.06), which keeps a checksum per entry, so no hash function is needed in a program. Criterion 1: the editor opens a .zpinball (Shift+Cmd+O, a drop on the window, the command line); it is read whole first, an altered one is refused ('Cannot open bad.zpinball: the file "x" was altered after the package was made') and nothing is unpacked; a good one is unpacked into a new folder beside it (name, 'name 2': never over a folder) and that folder is opened. Entry names that leave the folder ('..', absolute) are refused. Save as (Shift+Cmd+S) writes the table and its files in another folder, refused when that folder holds a table. Proof: next/tests/t1/pinball3d_editor_table.sh. Criterion 2: examples/pinball3d-editor/src/help.ts pairs each of the 321 help lines of the format with its French, keyed by the English text; the form shows it; selftest.ts fails and lists any line without French or any pair the format lost ('ok: every help line of the format has its French', asserted by pinball3d_editor.sh). Criterion 3: examples/pinball3d-editor/README.md (make a table, share a table, keys). Not done, from the description, no criterion: the mirror axis and the view kept with the folder; the constant of Latin characters (widgets.tsx DRAWN) is still there.
