## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ZN-592.01 split the window host (targets/macos/hal_sdl.cpp, hal_cocoa.mm) into libzn_host_window.a, but zinc build still links it, SDL3 and the frameworks into every program that calls the host: a console program with a setTimeout links 25 libraries (CoreFoundation's ~400 initializers, AppKit, Metal...) and starts in 14.3 ms on the Intel Mac against 4.7 for an empty program. Link the window host only into programs that draw (zinc:gfx rows, drawsOf), use zinc:gl or call native plugins (which may need SDL3); the others get hal_dispatch's headless HAL alone.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Done 2026-10-10 (D68). zinc build links the window host (libzn_host_window.a with -force_load), SDL3 and the frameworks only into programs that draw (drawsOf), use zinc:gl or call native plugins; hal_dispatch.cpp has weak stand-ins (ZN_WINDOW_SEPARATE) and hal_sdl.cpp's strong zn_window_load() says a window is linked. macOS links every program with -dead_strip (ZN-603 meant it, it sat in the arm64 block) and -no_exported_symbols (kept exported with a heap budget: libzn_rt_new's operator new must reach libc++'s allocations, tests/t1/aot.sh checks it). Fonts and images are baked only for programs that draw (AOT and the interpreter's cache). mimalloc built with MI_SKIP_COLLECT_ON_EXIT (its exit purge was 4 of 16 samples); the VM call stack is calloc'ed (no 240 KB zeroing at load).
Measured (Intel Mac, best of 40 interleaved, empty program 4.9 ms): console program with a timer 16.6 -> 7.0 ms (25 libraries -> libSystem + libc++, 3.9 -> 1.4 MB); console.log(1) compiled 6.6 -> 5.1 ms; zinc run of a cached program 5.2 -> 4.1 ms over the empty program.
AC1 not met strictly: 2.0-2.2 ms over the empty program (the host's row dispatch keeps ~240 libSystem imports): ZN-592.07. tests/t1/launch_time.sh now builds such a program (libSystem and libc++ only, prints 1, budget 3 ms): PASS. AC2: aot (t0, t1), gl_cube, native_plugins, window_renderer, run_compiled, templates_kickstart, launch_time PASS; T0 97/99 before two fixes: shared_headers (a #define outside include/zn, removed) PASS now, tls is the known ZN-610 failure. templates_kickstart failed on the 3d template's frame: ZN-563.04's highlights (its Standard materials, roughness 0.3/0.5), the frame checked by eye and its hash recorded in a separate commit.
