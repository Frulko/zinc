## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Part of ZN-371: zinc build --debug emits #line directives from the line table and keeps the source names of locals in the generated C++, compiled with -g, so lldb stops at a .ts line and prints locals.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented 2026-10-11 (after the 01:52-08:57 stall: launches hang while the screen is locked). zinc build --debug (src/main.cpp): the debug lowering (gDebug) and -O0 -g instead of -O2, local symbols kept (no -Wl,-x). src/aot/aot.cpp in a debug module: each emitted C++ line of a statement carries #line <line> "<absolute .ts>" (one directive would let the next C++ lines count up the .ts lines), #line 1 "zinc-runtime" around each function's own code; each local is a typed C++ variable under its source name (bool, std::int64_t, std::uint64_t, float, double, zn::rt::StrObj*/ArrObj*/Obj*; this -> self; C++ keywords and the emitter's names get a trailing _) updated after each Move/LoadI/LoadNull into its home register; compiled functions are named after the Zinc ones (fname(): add__t2, run__f1; normal builds keep f<i>/t<i>). Normal builds: the C++ of 4 programs (main.ts, nbody, breakout, conversions) byte-identical to before.
