## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
plugin.json publisher {name, publicKey} (a known key now). zinc add <URL>: tier community; with a publisher key and no --key, the archive is fetched again from the cache with that key so <url>.sig must verify; '<name>: tier community, publisher P (key xxxx..., pinned | unsigned | pinned by its commit), from <url>' printed before installing; the lock records publicKey, tier, publisher. A different key than the pinned one is refused with the reason and the zinc trust command; zinc trust <name> [dir] removes the pinned key. tests/t1/plugin_community.sh (a fork of device by Alice): first add prints and pins, built from source; version 2 with another key refused and the installed version kept; after zinc trust it is pinned; a missing .sig refused. tests/run --changed 53 pass. usage: n/a
