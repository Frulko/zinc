## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
What a table needs and a screen does not: panels and texts turn toward the side of the table the touch came from; several visitors use it at once, each in a zone or a floating panel of their own; large targets; an attract loop when nobody touches, and a reset to the start after a set idle time; kiosk behaviour (fullscreen, no way out by gesture, errors never shown to visitors). (Owner request, 2026-10-10: a demo app useful for mediation in museums: an interactive presentation on a touch table, photo gestures, 3D models, descriptions, presentations, in the manner of Klynt.)
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 scripted touches from the four sides open panels oriented to each side (pixel goldens)
- [ ] #2 two scripted visitors browse different sequences at the same time without affecting each other
- [ ] #3 after the idle time the app returns to the attract loop and all state is reset (log)
